targets, two of them written to be dropped rather than authored.

The pass used the one instrument CLAUDE.md names and no pass had run, the canon list
read forwards, and corrects what the file leads an author to expect from it: all 32

litigation selection is Only the Close Ones, tanking is The Cobra Effect. At this size
the binding constraint is no longer unstaged vocabulary, which is everywhere, but
unstaged mechanism, and thirty zeros can yield one candidate.
