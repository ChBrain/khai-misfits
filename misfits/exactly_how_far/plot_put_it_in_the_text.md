# Plot: Put It in the Text

## Taxonomy

[Exactly How Far](play_exactly_how_far.md)

## Owner

- Project: khai-misfits

## Cue

[The Treaty Text](place_the_treaty_text.md), where the wording has to be settled and nothing vague will do the job.

## Action

Through [Reassuring](process_reassuring.md), [the Patron](persona_the_patron.md) on [Set the Dial Where It Holds](plan_set_the_dial_where_it_holds.md) sets [the Published Map](piece_the_published_map.md): the territory named, the contingency named, the forces named, in language a legislature will ratify and an ally can quote. It is good drafting and it does exactly what it was meant to do. The scene closes with the ally satisfied, and with a public document that says, in the same words and with the same precision, what is not covered.

## Stage

This is craftsmanship, not carelessness. A clause loose enough to leave nothing exposed would have reassured no one, and the seat that produced it would have failed at the task it was given.

## Tension

The document has to be public to deter and public to reassure, so there is no version addressed to one reader, and every improvement the ally asked for is delivered intact to the party the treaty was written against.
