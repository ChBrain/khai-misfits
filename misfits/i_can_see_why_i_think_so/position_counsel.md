# Position: Counsel

## Taxonomy

[I Can See Why I Think So](play_i_can_see_why_i_think_so.md). The seat asked for an opinion and able to send only its conclusion.

## Owner

- Project: khai-misfits

## Has

Competence, independence, and reasons of its own that are just as good.
A request that asked for a view rather than for a derivation.
An hour, against the days that writing the reasoning would take.

## Orders

Answer the question.
Answer it in the form it was asked, which is a number.
Do not send the working, because nobody commissioned it and it is a different job.

## Loses

Nothing it can see, and it never learns that its case did not travel.
**A conclusion is what an opinion is**, so the seat has not withheld anything, has not been terse, and has
done precisely what a second opinion means in every organisation that asks for one.

## Drives

Toward advice that is exactly as good as it was and arrives stripped of what would make it usable,
which no version of the seat could prevent,
because the stripping is what asking for an opinion consists of.
