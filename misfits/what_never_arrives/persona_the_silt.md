# Persona: The Silt

## Taxonomy

[Silt](position_silt.md). The load nobody asked for, which is what a coastline is made of.

## Owner

- Project: khai-misfits

## Projection

Ordinary ground, taken off the land all the way down and carried in suspension.
Not a pollutant, not a nuisance, and not a resource anyone has ever put a price on. Simply what a river is carrying besides water.

## Action

Settles, once the current stops, onto the floor of [the still water](place_the_still_water.md).
Stays there, in a quantity that shows up in [the depth reading](piece_the_depth_reading.md) as lost storage and nowhere at all as undelivered land.

## Shadow

Cannot be noticed as missing, because missing is not a state anything reports.
There is no meter for what did not arrive, no line on any sheet for a delivery that was never contracted, and no moment when the absence begins: the load simply stops where the current stops, and stopping is not an act by anybody.

## Tell

Is counted, when it is counted at all, as a problem for the reservoir rather than for the coast: the same tonnes read as capacity lost upstream and are not read as land unmade downstream.
