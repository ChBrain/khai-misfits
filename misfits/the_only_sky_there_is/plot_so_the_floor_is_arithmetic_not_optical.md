# Plot: So the Floor Is Arithmetic, Not Optical

## Taxonomy

[The Only Sky There Is](play_the_only_sky_there_is.md)

## Owner

- Project: khai-misfits

## Cue

One draw, and a variance to be estimated from it.

## Action

[Counting the modes](process_counting_the_modes.md): [the mode counter](persona_the_mode_counter.md), holding [Mode Counter](position_mode_counter.md), derives [the mode count](piece_the_mode_count.md) and prints it as its own band.

## Stage

An exact expression for an uncertainty that contains no instrumental quantity at all.

## Tension

The floor is set by how many independent things there are, which is five at the largest scale, and by nothing else.
A sphere admits a fixed number of independent patterns at each angular scale, and estimating a variance from five numbers has a calculable spread whatever measured them. The derivation is exact, is agreed by everybody and is reported as a separate term rather than buried. Understanding it completely is the only thing that can be done to it, and a fully understood limit is not a smaller one.
