# Plot: So the Extra Draws Must Come From Inside

## Taxonomy

[The Only Sky There Is](play_the_only_sky_there_is.md)

## Owner

- Project: khai-misfits

## Cue

The floor, fully understood, and a determination to get under it.

## Action

[Borrowing another vantage](process_borrowing_another_vantage.md): [the reacher](persona_the_reacher.md), holding [Reacher](position_reacher.md), reconstructs the quadrupole seen from distant clusters.

## Stage

A real reduction of the floor, with a ceiling on it.

## Tension

More vantages can be found inside one universe, and the supply of independent ones is finite.
Light scattered in a distant cluster carries the quadrupole as seen from there and then, so each cluster is a partly independent view of the same field. The method is real and is being pursued, and it does lower the floor. Clusters near one another see correlated skies, so the gain stops at roughly the number of genuinely independent regions, which is set by the size of the thing being sampled. The remedy works, has an end, and the end is the same fact the play started from.
