# Plan: Compare to Last Decade

## Taxonomy

A **standing plan**: the intent of [the oncologist's seat](position_oncologist.md), inside [Better in Both](play_better_in_both.md).

## Owner

- Owner: [Oncologist](position_oncologist.md)

## Direction

Set this decade's survival beside last decade's, stage against stage. Do not pool the stages: a stage I case and a stage IV case are not the same case, and a single overall figure would track the changing mix of stages rather than the medicine, which is the cruder error and the one stage-specific reporting exists to avoid. Report what the comparison shows, since a field that declined to measure its own progress would fail a worse way. Trust the stage label to mean the same thing in both tables, which is the one assumption the yardstick rests on and the one neither table lets you check.

## Targets

- [ ] the comparison is stratified by stage, never pooled across unlike cases
- [ ] improvement is reported where the tables show it, without hedging the field's own progress away
- [ ] the same stage labels are read as denoting the same thing in both eras
- [ ] the instrument behind each table is not asked after, no column recording it
