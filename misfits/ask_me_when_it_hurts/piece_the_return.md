# Piece: The Return

## Taxonomy

[Ask Me When It Hurts](play_ask_me_when_it_hurts.md). The applied stakes: the visceral state passing and the calm self resuming, no better informed than before, carrying the gap into decisions made for or with someone else.

## Owner

- Project: khai-misfits

## Place

At [the Bedside](place_the_bedside.md), carried by [Asking](process_asking.md): a question asked as near the threshold as timing allows, standing in for a forecast the calm state cannot make on its own.

## Load Bearing

A patient in a calm consultation room honestly underpredicts how much a future pain state will drive their own choices, and so may decline in the calm state an intervention the gripped state will urgently want, or accept in the gripped state what the calm state would have refused, with real consequences for consent, treatment, and the directives a person leaves for a future self they cannot yet fully imagine (Loewenstein, 2005). The remedy of asking nearer the threshold is real: it narrows the distance between the state doing the deciding and the state that will live with the decision. But the calm self that returns once the state passes still cannot fully recall what it just felt, so the next plan is made no wiser than the last, and the asking must be done again each time.

## Apparent

Looks like the fix, a good-faith remedy that should close the gap for good; is actually a real but incomplete narrowing of it.
