# Plot: The Pull Arrives

## Taxonomy

[Ask Me When It Hurts](play_ask_me_when_it_hurts.md).

## Owner

- Project: khai-misfits

## Cue

At the Grip, the visceral state itself, real and involuntary, present now where it was only an abstraction before.

## Action

[The Hot Self](persona_the_hot_self.md), from [the hot self's seat](position_hot_self.md), on [Want This Now](plan_want_this_now.md) through [Wanting](process_wanting.md), holds [The Onset](piece_the_onset.md) at [The Grip](place_the_grip.md): attention narrowing onto the drive itself and whatever will relieve it.

## Stage

The state is not chosen or feigned; it occupies the mind fully while it is present, hunger, pain, fear, or desire, as real and legitimate as the calm state that came before it (Loewenstein, 1996). It arrives in the body first and the reasoning follows it, not the other way around. It does more than add urgency to the earlier plan's terms; it reorganizes what is weighed at all, so that considerations which sat comfortably in the calm accounting now barely register, and the relief close at hand crowds out everything set at a distance.

## Tension

A state as honest as the one it replaces.
