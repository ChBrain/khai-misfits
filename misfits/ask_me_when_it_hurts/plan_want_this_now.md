# Plan: Want This Now

## Taxonomy

A **standing plan**: the intent of [the hot self's seat](position_hot_self.md), inside [Ask Me When It Hurts](play_ask_me_when_it_hurts.md).

## Owner

- Owner: [Hot Self](position_hot_self.md)

## Direction

Want fully what the present state wants, since the state is real and involuntary and occupies the mind while it is here. Know that this want is honest and not a corruption of the calm plan it overrules, and that the plan being set aside was sincerely made and is being set aside just as sincerely.

## Orders

([The Hot Self](persona_the_hot_self.md) holds [the Onset](piece_the_onset.md) through [Wanting](process_wanting.md) at [the Grip](place_the_grip.md), attention narrowed onto the drive and its relief, and meets [the Reversal](piece_the_reversal.md).)

## Implementation

([Wanting](process_wanting.md) at [the Grip](place_the_grip.md) holds [the Onset](piece_the_onset.md), because the visceral state is real and involuntary, and meets [the Reversal](piece_the_reversal.md), the calm plan set aside because what is wanted has changed and not only how urgently it is wanted (Loewenstein, 1996).)

## Targets

- [ ] the visceral state is felt fully, real and involuntary, not chosen or feigned
- [ ] the want is honest, distinct from Starting Tomorrow's discounting of the same reward at a nearer distance
- [ ] the calm plan is set aside, not from weakness but because what is wanted has changed
- [ ] it is owned that the self who made the plan and the self who breaks it are, in this moment, honestly different
