## Cue

The same article, read by somebody who wants the arrangement gone.

## Action

[The Door](piece_the_door.md) is examined at [the text](place_the_text.md): the procedure that can improve anything can replace anything, and cannot be written to admit only improvements.

## Stage

A lawful route by which the whole document can be undone.

## Tension

No procedure can be drafted to permit good changes and refuse bad ones, because nothing inside a procedure can tell them apart.
A majority threshold measures agreement, not merit. A required delay measures patience. Neither reads the content, and any clause that tried would have to name in advance the changes a future generation may not want, which is the other article and a different problem. So the route out is not a loophole: it is the same door, used by somebody with the votes.
