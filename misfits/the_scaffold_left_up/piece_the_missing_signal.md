# Piece: The Missing Signal

## Taxonomy

[The Third Week](place_the_third_week.md). What there is instead of a marker.

## Owner

- Project: khai-misfits

## Place

Standing in for the turning point throughout [the third week](place_the_third_week.md), and consulted by [the designer](persona_the_designer.md) whenever the question is raised.

## Load Bearing

It is why care does not reach this, and it is an absence rather than an oversight.
The turn is continuous, private and per-learner, so there is no discrete event for an instrument to detect and no test in the course whose output moves when it happens: a designer looking harder finds the same nothing, and a designer who tested for it would need a per-person measure the format of a course does not admit.

## Apparent

Nothing missing at all. A room that looks exactly as it did last week.
No alarm, because there is no channel an alarm would come down.

## Yearbook

Does not resolve with time and is not narrowed by experience.
Widens with the size of the room, since more learners means more afternoons and one handout.
