## Tension

This is an absence rather than an oversight, so looking harder returns the same nothing.
There is no discrete event for an instrument to detect and no output in the course that moves when it happens, and a designer who wanted to test for it would need a per-person measure that the format of a course does not admit: one handout, one schedule, one room. The unit the place can act on and the unit the mechanism runs on are not the same unit, and no amount of care reconciles them.
