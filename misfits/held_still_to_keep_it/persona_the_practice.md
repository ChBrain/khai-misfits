# Persona: The Practice

## Taxonomy

[Practice](position_practice.md). The thing itself, which was never one thing.

## Owner

- Project: khai-misfits

## Projection

A way of going on, carried in a few hundred people who each do it slightly differently.
No score, no canon, and no version anybody would call the real one.

## Action

Gets done again, differently, on each occasion that calls for it.
Answers what is in front of it, which is how it stays worth doing.

## Shadow

Has no true form underneath the variation waiting to be recovered.
The differences are not corruption of an original, they are the process itself, so a faithful record of any one performance is not a record of the practice but a record of one occasion: there is nothing to be faithful to that is not a moment.

## Tell

Is identifiable only by stopping the thing that identifies it.
