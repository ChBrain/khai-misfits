# Place: The Inventory

## Taxonomy

[Held Still to Keep It](play_held_still_to_keep_it.md). The list, and the form that has to be filled in before anything can be done.

## Owner

- Project: khai-misfits

## Shown

A record with fields: a name, a place, a bearer community, a description of the element, a date of documentation.
Everything filled in accurately, by people who consulted the practitioners properly.

## Holds

[The Entry](piece_the_entry.md), complete and true about the day it describes.
[The Need for an Object](persona_the_need_for_an_object.md), which is what the form is made of.

## Offers

Standing: a budget line, a claim on a ministry's attention, and a reason for a school.
The only route by which anything can be protected at all.

## Withheld

Any field for the variation.
The form can record what was done and cannot record that it is done differently each time, because a description that says so protects nothing and cannot be checked against next year: so the one property that made the practice alive is the single property the instrument has no way to carry.
