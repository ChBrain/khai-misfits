# Plot: It Works in Anybody

## Taxonomy

[Good for Anyone](play_good_for_anyone.md)

## Owner

- Project: khai-misfits

## Cue

Red cells that carry none of the common markers: no A, no B, no RhD.

## Action

[The Blood That Suits Everybody](persona_the_blood_that_suits_everybody.md), holding [Blood That Suits Everybody](position_blood_that_suits_everybody.md), sits in [the fridge](place_the_fridge.md), available to every patient alive.

## Stage

This is an unambiguous clinical good, and not a scarce luxury version of anything: it is ordinary blood, minus the markers.

## Tension

Compatibility is an invitation rather than a surplus.
Because nothing in any recipient objects to it, every patient in the building is a potential claimant on it, while only a few are restricted to it. So the property that makes it a gift to the whole population is the same property that makes the whole population a draw on it, and there is one shelf. Nothing has gone wrong at this point and nothing needs to: the misfit is already fully specified by the biology.
