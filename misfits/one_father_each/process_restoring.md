# Process: Restoring

## Taxonomy

[One Father Each](play_one_father_each.md). Any departure from equal investment being driven back to it.

## Owner

- Project: khai-misfits

## Initiated by

A ratio away from parity, and the premium that follows.
At [the next generation](place_the_next_generation.md), through [allocating](process_allocating.md).

## Direction

Toward equal investment, from either side, always.
The step that is not what it looks like is this one: the restoring force is **stronger the better the ratio is**, since a son's value rises exactly with the female bias, so the population's best mixture is the least stable one it can occupy.
And there is no defection in it. Suppose universal agreement to produce daughters only, perfectly kept: the arrangement still fails, because one individual doing otherwise is not cheating, is not gaining at anybody's expense, and is simply making the offspring that returns more.

## Lever

[The rare-sex premium](piece_the_rare_sex_premium.md), which is not anybody's instrument.
Because the force is generated by the identity, it cannot be suspended by trust, agreement, punishment or communication, which is what separates this from every problem those things solve.

## Echo

A population at equal investment, producing fewer offspring per generation than it could.
[The better ratio](persona_the_better_ratio.md) is not a cooperation that failed: it is a state that was never available.
