# Plan: Put It Where It Returns Most

## Taxonomy

A **mandate**: the intent of [the allocator seat](position_allocator.md), inside [One Father Each](play_one_father_each.md).

## Owner

- Owner: [Allocator](position_allocator.md)

## Direction

Spend a finite amount of reproductive effort where the return is highest, which is whichever sex is currently rarer. Leave more grandchildren for it, which is the only sense in which any of this is right.

## Orders

([The Parent](persona_the_parent.md) allocates between sons and daughters, puts more into whichever returns more, and contributes invisibly to the ratio moving back.)

## Implementation

([The Lek](place_the_lek.md), where the return on a son is actually settled; the [allocating](process_allocating.md) process against [equal investment](piece_equal_investment.md); the aggregate showing only as [the restoring force](piece_the_restoring_force.md).)

## Targets

- [ ] the effort is finite and is spent where the return is higher
- [ ] the allocation is correct at the scale it is made on
- [ ] no single allocation moves anything visibly, so none could reasonably be made otherwise
- [ ] the aggregate of them is what holds the population at its least productive mixture
