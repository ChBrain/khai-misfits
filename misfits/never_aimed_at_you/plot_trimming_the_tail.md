# Plot: Trimming the Tail

## Taxonomy

[Never Aimed at You](play_never_aimed_at_you.md)

## Owner

- Project: khai-misfits

## Cue

[The Stewardship Round](place_the_stewardship_round.md), with a guideline, an audit sample and a rate that has risen every year the programme has run.

## Action

Through [Auditing](process_auditing.md), [the Steward](persona_the_steward.md) on [Cut the Ones That Should Not Have Been Written](plan_cut_the_ones_that_should_not_have_been_written.md) meets [the Trimmed Tail](piece_the_trimmed_tail.md): the antibiotic written for a viral illness, the course that ran too long, the broad agent used where a narrow one was identified, each challenged and each removed. The audit reports honestly that most prescribing is appropriate, which is a good result. The scene closes with real and necessary work aimed at the fraction that failed, and with the mass that generates the pressure having passed the audit.

## Stage

The programme is funded, staffed and effective at what it does. The harms it prevents are real, it has never claimed to have solved resistance, and it would be missed if it stopped.

## Tension

The instrument selects on appropriateness and the mass is appropriate, so widening the remit would mean removing prescriptions the guidelines require, which would stop this being stewardship and start it withholding indicated treatment.
