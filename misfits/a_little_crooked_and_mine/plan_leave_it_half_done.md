# Plan: Leave It Half Done

## Taxonomy

A **standing plan**: the intent of [the abandoner's seat](position_abandoner.md), inside [A Little Crooked, and Mine](play_a_little_crooked_and_mine.md).

## Owner

- Owner: [Abandoner](position_abandoner.md)

## Direction

Set the build aside before it is finished, for any ordinary reason, and hold the incomplete object honestly. Know that this leaves the value the finisher would have felt unearned, since the effect the labor generates requires completion and not merely time spent on the task.

## Orders

([The Abandoner](persona_the_abandoner.md) holds [the Unfinished](piece_the_unfinished.md) through [Abandoning](process_abandoning.md) at [the Shelf](place_the_shelf.md), possessing the incomplete object exactly as long as a finished one.)

## Implementation

([Abandoning](process_abandoning.md) at [the Shelf](place_the_shelf.md) holds [the Unfinished](piece_the_unfinished.md), because the build was set aside before completion, and no extra value attaches to it beyond what a stranger would see, proving that the effect tracks finishing and not mere possession or time spent (Norton, Mochon and Ariely, 2012).)

## Targets

- [ ] the build is set aside honestly, before reaching completion
- [ ] the incomplete object is possessed exactly as long as a finished one would have been
- [ ] no extra inflation is felt, distinguishing this from mere possession or time spent
- [ ] it is owned that completion, and not labor alone, is what the effect actually requires
