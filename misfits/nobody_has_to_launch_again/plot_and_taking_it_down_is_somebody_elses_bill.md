# Plot: And Taking It Down Is Somebody Else's Bill

## Taxonomy

## Cue

## Action

[Taking it down](process_taking_it_down.md): [the removal](persona_the_removal.md) captures and deorbits large derelicts, a few a year, for decades.

## Stage

The models say it would hold the line. It has never been run as a programme.

## Tension

The consent problem and the funding problem are the same problem.
Every object worth removing belongs to whoever launched it, and the volume it sits in has no jurisdiction, so a removal mission needs somebody else's permission to take somebody else's property out of nobody's place. The benefit is spread across everybody who uses the band and the bill sits with whoever volunteers, which is the shape that reliably produces nothing. So the only remedy that reaches the mechanism is technically credible, institutionally homeless, and has to run longer than any programme anybody has funded.
