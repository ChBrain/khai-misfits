# Process: Writing It After

## Taxonomy

[Built Before the Rule](play_built_before_the_rule.md). A requirement produced by the failure that demonstrated it.

## Owner

- Project: khai-misfits

## Initiated by

A collapse, an inquiry and a finding.
[The Code That Came After](persona_the_code_that_came_after.md), holding [Code That Came After](position_code_that_came_after.md).

## Direction

Toward a new clause that is a genuine improvement, bought with a real catastrophe.
Toward effect from the date of enactment, forward only.

## Lever

Hindsight, which is the only source the requirement could have had, since nobody knew what to demand until something demonstrated it.

## Echo

A code that gets better after every disaster, improving only for buildings that were not standing when it happened.
