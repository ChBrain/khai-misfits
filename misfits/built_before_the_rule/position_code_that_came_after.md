# Position: Code That Came After

## Taxonomy

[Built Before the Rule](play_built_before_the_rule.md). The seat that can only ever arrive late and reach forward.

## Owner

- Project: khai-misfits

## Has

A body of requirements assembled disaster by disaster, each clause bought with a catastrophe.
A date of enactment, and effect from it.

## Orders

Improve after every failure.
Apply to what is built from now on.

## Loses

Both directions at once, and neither loss is a fault.
The requirement could not have been written before the event that demonstrated it, so the lateness is not sloth; and applying it backward would condemn the entire existing stock of the jurisdiction on the day of enactment, which no city can afford, so the prospective limit is not a favour to industry: the seat is bounded in time at both ends by facts rather than by choices.

## Drives

Toward a code that gets better with every disaster, and better only for buildings that were not standing when it happened.
