## Tension

The safety rule has made touching the unsafe thing the most expensive available act.
The official can see this coming, is required to produce it, and would be acting improperly to do anything else, since a threshold that bent for a sympathetic owner would bend for a well-connected one: the evenness that makes the rule fair is the same evenness that makes it unreachable. There is no power anywhere in the building to trade a partial improvement for a partial exemption, which is the one exchange that would help.
