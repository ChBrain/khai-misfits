# Persona: The Code That Came After

## Taxonomy

[Code That Came After](position_code_that_came_after.md). The requirement, written in the wreckage and applied forward.

## Owner

- Project: khai-misfits

## Projection

A body of requirements assembled disaster by disaster: a collapse, an inquiry, a finding, a clause.
The reason modern buildings survive things that used to kill people, and none of it available before the event that taught it.

## Action

Improves, genuinely, after each failure.
Applies to everything built from the date of enactment onward, and to nothing built before.

## Shadow

Could not have arrived any earlier, and cannot be applied any wider.
Nobody could have required reinforcement before the earthquake that demonstrated why, so the lateness is not sloth: and retroactive application would condemn the whole existing stock of a jurisdiction on the day of enactment, which no city can afford and no legislature will do, so the prospective limit is not a concession to industry either.

## Tell

Gets better with every catastrophe, and each improvement lands only on buildings that were not there for it.
