# Persona: The Task

## Taxonomy

[Task](position_task.md), inside [The Skill to See It](play_the_skill_to_see_it.md). The archetype of the thing done and judged, whose doing and whose judging draw on one and the same skill, so that it hands whoever attempts it a ruler made of the very thing being measured.

## Owner

- Project: khai-misfits

## Projection

A plain, fair test, the same for all. It looks like a neutral thing anyone may attempt and anyone may grade, a task that asks only to be done and honestly assessed.

## Action

Exact one skill for both. At [the Test](place_the_test.md), on [One Skill for Both](plan_one_skill_for_both.md) through [Doubling](process_doubling.md), the Task sets [the Double Duty](piece_the_double_duty.md): to tell a good answer from a bad one it demands the same knowledge that makes a good answer, so the doing and the judging are drawn from the one skill and cannot come apart.

## Shadow

Its fairness is the very source of the trap. Because the Task can be judged only by the skill it takes to do it, it gives the unskilled a broken ruler and the skilled a true one, not by any design but by the plain structure of what it asks, so the measure a person gets is only as good as the skill they were measuring. It means nothing by it and favours no one; the trap is in the shape of the task and not in any intent.

## Tell

To grade it well you must be able to do it well, so it grades its worst students in their own broken hand.
