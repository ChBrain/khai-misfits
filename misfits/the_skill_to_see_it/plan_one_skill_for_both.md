# Plan: One Skill for Both

## Taxonomy

A **standing plan**: the intent of [the task's seat](position_task.md), inside [The Skill to See It](play_the_skill_to_see_it.md).

## Owner

- Owner: [Task](position_task.md)

## Direction

Ask of the judging the same competence you ask of the doing, so that whoever would rate the work must be able to do the work, and hand each attempter a ruler that is only as true as the skill they brought. Know that your fairness is the source of the trap, that by asking one skill for both you give the unskilled a broken ruler and the skilled a true one, not by design but by the plain shape of what you ask.

## Orders

([The Task](persona_the_task.md) sets [the Double Duty](piece_the_double_duty.md) through [Doubling](process_doubling.md) at [the Test](place_the_test.md), demanding the same skill to grade the work as to do it.)

## Implementation

([Doubling](process_doubling.md) at [the Test](place_the_test.md) fuses the doing and the judging, because to tell a good answer from a bad one is itself an exercise of the field, so [the Double Duty](piece_the_double_duty.md) hands each attempter a ruler made of their own skill.)

## Targets

- [ ] the judging is shown to draw on the same skill as the doing, one competence for both
- [ ] the fusion is understood to hand the unskilled a broken ruler and the skilled a true one
- [ ] the evenness is seen to favour no one, the same test and grading offered to all
- [ ] the trap is owned as structural, built into the shape of the task and needing no ill will
