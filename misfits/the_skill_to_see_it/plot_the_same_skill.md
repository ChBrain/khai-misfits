# Plot: The Same Skill

## Taxonomy

[The Skill to See It](play_the_skill_to_see_it.md).

## Owner

- Project: khai-misfits

## Cue

At [The Test](place_the_test.md), a task has been done. Now it must be judged,
and the sitting has no one else in the room to do the judging.

## Action

[The Task](persona_the_task.md), from [the task's seat](position_task.md), on
[One Skill for Both](plan_one_skill_for_both.md) through
[Doubling](process_doubling.md), sets [The Double Duty](piece_the_double_duty.md)
at [The Test](place_the_test.md): telling a good answer from a bad one draws on
the very skill that makes a good answer, so doing the task and judging it are
one skill wearing two hats.

## Stage

To tell a good answer from a bad one is itself an exercise of the field, not a
vantage outside it (Kruger and Dunning): the same competence that produces the
work is asked, in the same sitting, to grade it. This is not I Know How It
Works, the illusion of grasping a mechanism that punctures the moment it is
traced and that catches everyone equally regardless of standing. Here the
deficit sits one level up, in the self-assessment of one's own skill at the
task rather than in tracing how something works, and it is self-masking in a
way that mechanism-tracing is not: the very faculty that would notice the gap
is the one in short supply, so it presses hardest on those furthest from the
competence that would let them see how far short they fall.

## Tension

The ruler for the work is the very skill the work takes.
