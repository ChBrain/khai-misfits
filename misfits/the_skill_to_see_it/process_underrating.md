# Process: Underrating

## Taxonomy

[The Skill to See It](play_the_skill_to_see_it.md). Borne at [The Mirror](place_the_mirror.md), precipitated by [The Expert](persona_the_expert.md), in [Easy for Anyone](plot_easy_for_anyone.md).

## Owner

- Project: khai-misfits

## Initiated by

A task that felt easy.
The ease is real, but the reading taken from it is not checked against anyone else's experience of the same task.

## Direction

From the ease felt toward a self-placement set too low.
What was effortless for this one mind is quietly assumed effortless for every mind in the room.

## Lever

A false consensus reads the task's ease as everyone's ease, so the expert's real distance above the rest goes unseen (Dunning).
The very fluency that marks the skill is what hides how uncommon that fluency is.
