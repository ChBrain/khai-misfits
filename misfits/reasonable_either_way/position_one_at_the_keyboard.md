# Position: One at the Keyboard

## Taxonomy

[Reasonable Either Way](play_reasonable_either_way.md). The seat that must exercise judgement, and can only exercise it on what it can see.

## Owner

- Project: khai-misfits

## Has

The question, written down before the file arrived.
Every choice the analysis needs: what to exclude, what to transform, how to group, what to control for.
A full record of each one, available to anybody who asks.

## Orders

Look at the data, because an analysis made blind to them would be worse.
Choose what a careful person would choose, and write down why.
Run it once, and report what was run.

## Loses

The ability to make its p-value mean what it says.
Not by any misstep: the number is computed correctly on the analysis that was run, and it is the wrong number anyway, because it prices the surprise of this result against one route when the data were free to suggest a different route and a different route would have been taken.

## Drives

Toward good judgement, which requires seeing the data, and away from a claim that only holds if the path was fixed before the data were seen, so the seat's competence and its problem are one act.
