# Plot: The Paths Not Walked

## Taxonomy

[Reasonable Either Way](play_reasonable_either_way.md)

## Owner

- Project: khai-misfits

## Cue

The same decision points, held against numbers that did not arrive.
[The Garden](persona_the_garden.md), which has no location, standing behind every turn already taken.

## Action

[Branching](process_branching.md): [The Garden](persona_the_garden.md), holding [Garden](position_garden.md), grows the routes that were available and were not walked, none of them run, none of them recorded, all of them defensible.

## Stage

No one stages this, which is the point: there is no scene, no act and no actor, only the fact that the turns could have gone otherwise and would have, had the file differed.

## Tension

The multiplicity is real and there is nothing anywhere that records it.
An auditor can be told the whole truth and learn nothing about it, because auditing examines what happened and this is made of what did not. The one question that would size the garden, what would you have done with different numbers, cannot be answered honestly by anyone, including the analyst, who would have had to see them first. So a record with no trace of alternatives is indistinguishable from a record where there were none.
