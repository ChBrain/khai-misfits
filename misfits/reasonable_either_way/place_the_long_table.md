# Place: The Long Table

## Taxonomy

[Reasonable Either Way](play_reasonable_either_way.md). Where the data are visible and the choices are made, in that order.

## Owner

- Project: khai-misfits

## Shown

The file, open. Distributions, plotted. Three records that are plainly wrong. A variable with a long tail. A group with eleven members in it.
Everything a careful analyst needs to see in order to decide well, all of it visible before the first decision is taken.

## Holds

[The Exclusion](piece_the_exclusion.md), written once the bad records are seen.
[The Covariate](piece_the_covariate.md), added once the groups are seen to differ.
[The Line at Point Oh Five](piece_the_line_at_point_oh_five.md), which was set long before anybody sat down.

## Offers

Everything, openly, to whoever is sitting at it.
No obstruction, no missing column, no hidden step. Sight of the data is exactly what the table is for.

## Withheld

Any view of what this table would have looked like with a different file on it.
Not hidden: absent. The comparison that would show what the choices owe to the data cannot be laid out here, because it would require a second dataset that was never collected and a second analyst who never sat down.
