# Persona: The Garden

## Taxonomy

[Garden](position_garden.md). The branches that were available and were not taken, which is where the multiplicity lives.

## Owner

- Project: khai-misfits

## Projection

Invisible, and enormous.
Not a set of analyses anyone ran, nor a set anyone considered and rejected: the analyses that would have been _obvious_ had the data been otherwise. It has no file, no log, no record, and no size that anyone can state.

## Action

Rearranges itself around whatever numbers arrive, so that whichever path is walked appears, from inside, to have been the only sensible one.
Grows a defensible route to almost any destination the data happen to suggest.

## Shadow

Cannot be inspected, counted, or disclosed, which is not concealment but a property of not having happened.
An auditor can be told everything true and still learn nothing about it. The one question that would size it, what would you have done with a different file, is a question the analyst cannot answer honestly except by saying they would have had to see it first.

## Tell

Leaves nothing at all behind, and its absence is read as cleanliness, since a record with no trace of alternatives looks exactly like a record where there were none.
