# Plot: And the Older Name May Be One Nobody Has Used

## Taxonomy

[The Name Does Not Move](play_the_name_does_not_move.md)

## Owner

- Project: khai-misfits

## Cue

A forgotten description from 1830, rediscovered, of the animal everybody now calls something else.

## Action

[The Priority Rule](piece_the_priority_rule.md) is applied at [the literature](place_the_literature.md), and the binomial of thirty years' standing is the junior one.

## Stage

A correct application of a fair rule, about to move a name under a schedule, a statute and a database.

## Tension

The rule is working exactly as designed, and the cost falls on everything built while it was not being applied.
Nothing here is a malfunction: the older publication exists, priority is the rule, and the rule is objective precisely so this cannot be argued about. But [the literature](place_the_literature.md) is an index whose value is that one string reaches one thing across decades, and nothing in a conservation schedule or an ecological time series announces that the string now means something else. So the injury lands on the constituency that most needs the rule to be rigid.
