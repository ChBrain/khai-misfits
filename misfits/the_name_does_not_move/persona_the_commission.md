# Persona: The Commission

## Taxonomy

[Commission](position_commission.md). The one that can move a name, and rations it.

## Owner

- Project: khai-misfits

## Projection

A petition, a case file, published comment from the field, and a power to set the rules aside.

## Action

Hears the case.
Rules, occasionally, that the ordinary rule shall not apply to this one name.

## Shadow

Holds the escape hatch and must keep it narrow to keep it worth having.
The power exists precisely because the rules produce results nobody wants, and it works: names in universal use are conserved, forgotten senior synonyms are suppressed, and the literature is spared. It also has to be used sparingly, because a rule set aside whenever it is inconvenient is a rule that nobody can rely on, which was the reason for having it. So the seat cannot grant every deserving case without destroying the property that makes the grant valuable.

## Tell

Fixes what it can afford to fix, and the affordability is the constraint.
