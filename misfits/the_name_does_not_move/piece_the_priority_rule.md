# Piece: The Priority Rule

## Taxonomy

[The Literature](place_the_literature.md). The oldest name wins, which settles it and sometimes wrecks it.

## Owner

- Project: khai-misfits

## Place

Applied at [the literature](place_the_literature.md) whenever two names are found to mean one thing, and overridden only by [the ruling](piece_the_ruling.md).

## Load Bearing

It removes discretion completely, and removing discretion is exactly what produces the outcomes nobody wants.
Whoever published first wins, which is a fact anybody can check and nobody can argue with, so the rule ends disputes instead of hosting them. It also means a binomial in universal use for a century can be displaced by a description from 1830 that nobody has cited since, and the rule cannot tell the difference, because telling the difference would require the judgement it was adopted to eliminate.

## Apparent

Fair procedure. First come, first served.

## Yearbook
