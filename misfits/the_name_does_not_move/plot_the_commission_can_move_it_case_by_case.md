# Plot: The Commission Can Move It, Case by Case

## Taxonomy

[The Name Does Not Move](play_the_name_does_not_move.md)

## Owner

- Project: khai-misfits

## Cue

A petition asking that the rules not apply to one name.

## Action

[Petitioning the commission](process_petitioning_the_commission.md): [the commission](persona_the_commission.md), holding [Commission](position_commission.md), publishes the case, takes comment, and issues [the ruling](piece_the_ruling.md).

## Stage

A name conserved, a literature spared, and a file closed.

## Tension

The discretion is not removed by the codes and not restored by the commission: it is relocated, rationed and made expensive.
The power exists because the rules do produce results nobody wants, and it works. It must also stay scarce, because a rule set aside whenever it is inconvenient offers nobody anything to rely on, which was the reason for having one. So the seat cannot grant every deserving case without destroying the property that makes a grant valuable, and the number of names that ought to be moved will always exceed the number that can be.
