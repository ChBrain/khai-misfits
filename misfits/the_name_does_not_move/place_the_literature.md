## Offers

## Withheld

Any tolerance for the string changing meaning.
The place is an index, so its whole value is that the same name reaches the same thing in 1994 and in 2026. A name that tracked the current best phylogeny would move quietly under every instrument keyed to it, and nothing in a schedule or a dataset announces that it now means something else. So the demand for rigidity comes from here rather than from the code, and the code is answering it.
