# Plot: So It Is Anchored to One Individual and One Date

## Taxonomy

[The Name Does Not Move](play_the_name_does_not_move.md)

## Owner

- Project: khai-misfits

## Cue

Two names found to refer to one animal, and a question of which stands.

## Action

[The Priority Rule](piece_the_priority_rule.md) is applied at [the literature](place_the_literature.md): whoever published first wins.

## Stage

A dispute ended by a fact anybody can check.

## Tension

The codes anchor twice, to an object and to a date, and both anchors are chosen for being uncontestable rather than for being right.
Priority removes discretion as completely as the type does: there is no arguing about which publication is older. That is what makes it work, and it is the same property that makes it produce outcomes nobody wants, since the rule cannot distinguish a binomial in universal use from a description nobody has cited since 1830. Telling them apart would require the judgement the rule exists to eliminate.
