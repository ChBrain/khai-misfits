# Plot: A Name Has to Be Anchored to Something

## Taxonomy

[The Name Does Not Move](play_the_name_does_not_move.md)

## Owner

- Project: khai-misfits

## Cue

A new species being described, and the question of what the name will refer to.

## Action

[Designating the type](process_designating_the_type.md): a describer fixes the name to one individual, which enters [the type drawer](place_the_type_drawer.md).

## Stage

A referent that is physical, singular and inspectable.

## Tension

A name with no fixed referent is not a name, so the anchor is not a choice the codes made among options.
If the referent were a description, the description would need interpreting and two workers would interpret it differently. If it were a population, the population's boundary is the thing under dispute. An individual in a jar cannot drift, cannot be reinterpreted and cannot be argued about, which is the entire specification. Nothing in that specification asks the individual to be typical, because typicality is a judgement and a judgement is what was being avoided.
