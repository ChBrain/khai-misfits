# Play: The Name Does Not Move

## Estate

[khai-misfits](https://github.com/ChBrain/khai-misfits): the house that holds this production and answers for the whole run.

## Name

The Name Does Not Move.
A species name is fastened to one animal in a jar and to the date somebody published it. If the animal turns out to be a juvenile, a hybrid or an outlier, everybody can see that, and the name stays on it. If a forgotten description from 1830 turns up, that name wins, however long the current one has been in use.

## Arc

The bend is this: the anchors were chosen for being uncontestable rather than for being right, and being uncontestable is what makes them sometimes wrong and always immovable.
It runs on a name needing a referent.
[A Name Has to Be Anchored to Something](plot_a_name_has_to_be_anchored_to_something.md). A description needs interpreting and a population's boundary is the thing in dispute, so [the holotype](piece_the_holotype.md) is one animal that cannot drift, be reinterpreted or be argued about.
And the codes anchor twice.
[So It Is Anchored to One Individual and One Date](plot_so_it_is_anchored_to_one_individual_and_one_date.md). [The Priority Rule](piece_the_priority_rule.md) removes discretion as completely as the type does, which is what makes it work.
And the individual may be atypical, visibly.
[And the Individual May Be Atypical, Visibly](plot_and_the_individual_may_be_atypical_visibly.md). [The Reviser](persona_the_reviser.md) demonstrates it conclusively and is believed at once, and the name does not move, so the field knows exactly what is wrong and the knowing changes nothing.
Then [And the Older Name May Be One Nobody Has Used](plot_and_the_older_name_may_be_one_nobody_has_used.md).
A description from 1830 displaces a binomial of thirty years' standing, correctly, under a schedule and a database that will not announce the change.
And [the commission can move it, case by case](plot_the_commission_can_move_it_case_by_case.md). [The Ruling](piece_the_ruling.md) works and must stay scarce, so the discretion is relocated and rationed rather than removed or restored.
And [anchoring to the biology moves the anchor into the argument](plot_and_anchoring_to_the_biology_moves_the_anchor_into_the_argument.md). [The Reformer](persona_the_reformer.md) ties the name to a clade, which is correct and depends on a hypothesis the discipline exists to revise.

## Stakes

Whether a name can be both a fixed handle and a true description.
Every plot moves the same way: toward an anchor chosen for being uncontestable, a second anchor chosen the same way, an error everybody can see and nobody can act on, a rule working exactly as designed against everything built on it, a discretion relocated and rationed rather than removed, and a reform that trades fixity for correctness without escaping the trade, and away from any account in which a code was written badly or a committee was obstinate. The production cannot fault the codes, because a name whose referent needs interpreting is not a name; and it cannot fault the reviser, the commission or the reformer, all of whom are doing the only thing their seat permits. What is left to fight over is not which anchor to choose but what to call a system that must buy a fixed handle with accuracy and knows the price.
