## Load Bearing

High value is created only by long chains of complementary tasks all done well: a rocket, a legal brief, a surgery, a piece of software, each needs many things done right and none done badly (Kremer). The more tasks such a product needs, the more fragile it is, since any one task done poorly can cut the whole. Guard against reading a longer chain as merely more work, a bigger list to get through: the real cost of length is not effort but exposure, since each added task is another place a weak link can ruin the product.
