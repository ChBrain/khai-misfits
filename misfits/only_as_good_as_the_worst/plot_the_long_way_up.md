# Plot: The Long Way Up

## Taxonomy

[Only as Good as the Worst](play_only_as_good_as_the_worst.md)

## Owner

- Project: khai-misfits

## Cue

[The Assembly](place_the_assembly.md), a chain that cannot yet bear a high value, because its weakest task cannot.

## Action

[The Improver](persona_the_improver.md), from [the improver's seat](position_improver.md), runs [Lift the Floor](plan_lift_the_floor.md) through [Lifting](process_lifting.md), holding [The Bound](piece_the_bound.md): raising the quality of the weakest tasks, one by one, or shortening the chain so fewer tasks can drag it down, or building in redundancy so no single task's failure multiplies unchecked. The scene closes with the floor lifted at real and considerable cost, the chain now able to bear more than it could before, and the way up shown to be long and hard rather than a single fix.

## Stage

A chain bears a high value only when its weakest task can bear it, so development, on this account, means lifting every weak link in turn, each lift costly on its own terms (Kremer). The effect softens where tasks can be made substitutable for one another or backed up with redundancy: a weak task that no longer has to multiply against the rest no longer sets the ceiling alone. Where that softening is not yet possible, the floor must be lifted directly, task by task.

## Tension

The fix is to raise the worst task everywhere at once, not the best task anywhere, and that is the whole difficulty of development.
