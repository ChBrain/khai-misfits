# Persona: The Firm

## Taxonomy

[Firm](position_firm.md). The one who builds high-value output that needs every task done well, and so matches skill with skill, taking only high-quality inputs and turning away any that would be the weak link.

## Owner

- Project: khai-misfits

## Projection

Exacting, rational, meritocratic.
Does work whose value is the product of its tasks' qualities, so it needs every task done well and cannot let one spoil the whole.
No cruelty in it: it would gladly hire more, but a task placed in unreliable hands would waste all the excellent work around it, so it must choose by quality.

## Action

Keeps no weak links on [No Weak Links](plan_no_weak_links.md), through [Matching](process_matching.md) at [the Gate](place_the_gate.md), taking [the Match](piece_the_match.md), admitting only high-quality inputs and pairing skill with skill, because a skilled worker adds far more beside peers than beside a weak link.
Cannot open its high-value chain to an input whose quality would cut the product, because the value multiplies and the worst task caps the whole, so its sorting is the value-maximising response and not a preference.
Does what a firm doing exacting work must do: it matches high with high, and leaves the lower quality to lesser chains.

## Shadow

Not a snob and not cruel: the Firm's refusal follows from the multiplicative structure, since placing a task that could spoil the whole in unreliable hands would waste the excellence around it, so it turns the low-skill away soundly.
Because the same multiplication that makes it prize the skilled makes one weak link ruinous, the Firm cannot both reward quality together and admit the low, so the one hiring the best is the one that shuts the rest out.
It is the maker of high value and the gate that strands the low-skill, no malice in either.

## Tell

Says it hires only the best because the work demands it, and is right, the work does.
Cannot take the willing low-skill worker, because on its chain their quality would be multiplied through and cut the whole, so it matches skill with skill and the sorting it makes it does not intend as exclusion.
