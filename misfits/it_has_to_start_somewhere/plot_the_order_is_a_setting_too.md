# Plot: The Order Is a Setting Too

## Taxonomy

[It Has to Start Somewhere](play_it_has_to_start_somewhere.md)

## Owner

- Project: khai-misfits

## Cue

A page with nothing preselected, and two options printed one above the other.

## Action

[The Order of the Options](piece_the_order_of_the_options.md) is examined at [the drafting table](place_the_drafting_table.md) after the preselection has already been removed.

## Stage

A remedy applied in full, and a measurable effect still standing behind it.

## Tension

A list has to be in some order, so the setting survives the removal of the setting.
Position moves the answer wherever it has been measured, on ballots, on menus and on ranked results, and being first is worth something to whoever is first. Randomising the order does not delete the effect; it spreads it evenly, which is a policy of its own and a decision somebody made. So the difficulty is not a property of preselected boxes that better forms could design out. It is a property of putting a question to anybody at all, and it is why [the registrar](persona_the_registrar.md) cannot be relieved of the seat by being more careful in it.
