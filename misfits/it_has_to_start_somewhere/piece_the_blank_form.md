## Load Bearing

It has to hold a state before anybody arrives, and every state it can hold is a different one.
This is not a fact about paper. Any question put to anybody arrives in some condition: presumed one way, presumed the other, or demanding an answer, and each produces a measurably different distribution from the same population with the same stated attitudes. There is no fourth condition and no null condition, which is why the object everybody asks for, a form that leaves the question entirely to the person, is not a form anybody has ever been able to print.
