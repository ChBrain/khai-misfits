# Place: The Drafting Table

## Taxonomy

## Shown

A layout, a set of boxes, a running order, a legal duty and a print date.
Ordinary institutional work: minuted, reviewable, and done by people with no stake in which way the answers go.

## Offers

## Withheld

A neutral option to put on the page.
The place has a finite list of arrangements and no zero on it: presuming in, presuming out and demanding an answer all produce different distributions, and so does the order the options are listed in, so the request that arrives here most often, for a form that leaves the question to the public, is a request for an object that does not exist.
