# Process: Setting the Initial State

## Taxonomy

[It Has to Start Somewhere](play_it_has_to_start_somewhere.md). The act that cannot be declined.

## Owner

- Project: khai-misfits

## Initiated by

A form that has to exist, and a page that has to be finished.
[The Registrar](persona_the_registrar.md), holding [Registrar](position_registrar.md), at [the drafting table](place_the_drafting_table.md).

## Direction

Toward a printable page, chosen from a finite list of arrangements.

## Lever

The duty to issue the form, which admits of no version in which the page is left unfinished.

## Echo

A form that works, and a distribution of answers that would have been different on any other arrangement.
