# Process: Filling It In

## Taxonomy

[It Has to Start Somewhere](play_it_has_to_start_somewhere.md). The free and unpressured answer.

## Owner

- Project: khai-misfits

## Initiated by

A form to be returned.
[The Chooser](persona_the_chooser.md), holding [Chooser](position_chooser.md), at [the counter](place_the_counter.md).

## Direction

Toward a completed return, changed where there is a view and left where there is not.

## Lever

Full freedom to answer either way, at a cost of a moment, with nothing hidden.

## Echo

A return that is honest throughout, and that reports the setting on every question the person had no preference about.
