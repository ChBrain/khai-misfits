# Plot: The Wire Goes Quiet

## Taxonomy

[Both Take the Crown](play_both_take_the_crown.md)

## Owner

- Project: khai-misfits

## Cue

[The Link](place_the_link.md), the network path between the nodes, holding until it does not.

## Action

Through [Partitioning](process_partitioning.md), [The Partition](piece_the_partition.md) cuts the cluster in two, and [The Silence](piece_the_silence.md) falls: [The Isolated](persona_the_isolated.md), from [the isolated's seat](position_isolated.md), can no longer hear its peer, and cannot tell whether that peer has crashed or is merely unreachable. The scene closes with the cluster split, each side alive and blind to the other, silence meaning both things at once (Fischer, Lynch, and Paterson).

## Stage

Nothing has crashed: every node is up and working, and only the link between them has failed, so the cluster is not dead but holed, two live halves that can each reach themselves and not the other, and the quiet on the wire says dead and unreachable in the same breath.

## Tension

The one thing a node would need to know, whether its peer is alive, is the one thing the silence hides, and it cannot wait to find out, because waiting is itself a choice and the answer may never come, so the trap is set the instant the wire goes quiet.
