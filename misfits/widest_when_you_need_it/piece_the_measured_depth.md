# Piece: The Measured Depth

## Place

## Load Bearing

It is true, current, and about a market in which the quoter's odds were ordinary.
Depth observed when flow runs both ways is a measurement of a state in which the chance that any one seller knows something is average. On a day when the reason to sell is shared, that chance is not average and the quantity being estimated is a different quantity, so the number is not stale or sloppy: it is a correct measurement of something else. Assuming worse is possible, costs return on every day it is not needed, and somebody answers for that cost too, which is why the honest number is the one that gets used.
