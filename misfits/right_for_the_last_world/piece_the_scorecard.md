# Piece: The Scorecard

## Taxonomy

[Right for the Last World](play_right_for_the_last_world.md). The performance record: throughput, cost, the figures the Rulebook's fit is read through.

## Owner

- Project: khai-misfits

## Place

At [the Review](place_the_review.md), laid on the table each quarter for the room to read together.
Cited at [the Chart](place_the_chart.md), where it stands behind every seat won on the criteria it certified.

## Load Bearing

Without it there is no way to say the structure is working at all, only an impression, and impressions do not build careers or certify a form.
With it the structure has proof it can point to, checkable, consistent, and hard to argue with on its own terms. The Scorecard is load bearing because it is where performance is read as evidence of the form itself rather than of the match (Donaldson): a fit and performance travel together for as long as the fit holds, so the record cannot, from inside its own numbers, tell a reader which one it is actually confirming, and the piece is load bearing exactly because that confusion is not a flaw in it, it is the only kind of number an instrument built this way could ever return.

## Apparent

Objective, the plain, hard evidence that settles an argument by being looked at.
Seen in the Review room, the Scorecard looks like the last word on whether things are working, and the truth that it was built by the very structure it is now asked to judge, that a clean reading proves the structure is running as designed and nothing about whether the design still answers the world, stays hidden behind how solid a good number feels in the hand.
