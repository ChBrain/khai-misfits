# Place: The Market

## Taxonomy

[Right for the Last World](play_right_for_the_last_world.md). The environment that sets the real requirement the structure is built to answer, and moves without announcing that it has.

## Owner

- Project: khai-misfits

## Shown

Order after order, arriving at a volume steady enough to plan against.
The same shape of case, repeated at scale, so that a rule written for this quarter is still the right rule the next, and the whole run of them reads, from the inside, as proof that whatever answers it correctly will keep on being asked to.

## Holds

The one figure that matters most and is never itself written down anywhere inside the structure: how much of what arrives still looks like what used to arrive.
Here the requirement lives before it is ever translated into a rule, so the Market holds the true shape of the demand, in full, while every instrument built to read it holds only the shape it was built to expect.

## Offers

A genuine reward to whoever answers its requirement well, in the terms it is currently asking in.
Because the reward really is earned by the fit, not handed out on faith, the Market offers a structure that matches it a return worth building a career on, so it hands out, faithfully, the exact confirmation that will later make the same structure impossible to doubt.

## Withheld

Any notice that the requirement has changed.
The Market does not send word when it turns, because turning is not an event inside the structure that is meant to hear it, it is a change out here, so it withholds the one thing the structure would need to feel the shift in time, and it withholds it not out of concealment but because nothing about a requirement moving obliges the world to announce it to the instrument built for the requirement it used to have.
