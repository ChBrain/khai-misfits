# Plan: Hold the Fit

## Taxonomy

A **standing plan**: the intent of [the Steward's seat](position_steward.md), inside [Right for the Last World](play_right_for_the_last_world.md).

## Direction

Read the market's requirement, build the structure that answers it, and run that structure exactly as built. Trust a clean result as confirmation the structure still answers correctly, and keep running it that way for as long as the results keep confirming.
