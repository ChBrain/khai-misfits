# Place: The Review

## Taxonomy

[Right for the Last World](play_right_for_the_last_world.md). The recurring room where the structure's results are read aloud and given a meaning.

## Owner

- Project: khai-misfits

## Shown

A quarter's worth of figures, set on the table for everyone present to read together.
The same room, called on the same terms each time, so that whatever is decided here reads not as one person's judgement but as the structure's own considered word on itself.

## Holds

The Scorecard, and whatever else is brought to be set beside it.
Here the room holds the only ritual the place has for asking whether things are working, so it is the one place a challenge to the structure and the structure's own defence of itself can be laid on the same table and looked at together.

## Offers

A hearing to whatever evidence is brought into the room, on the day it is brought.
Because the room exists to ask the question, not to answer it in advance, the Review offers the Backlog the same table the Scorecard has always had, so it offers the one chance the newer evidence gets to be weighed rather than simply outvoted by habit.

## Withheld

A verdict the evidence in the room cannot itself supply.
The Review can set two readings side by side and cannot manufacture the number that would settle between them, because that number belongs to an instrument the structure has not built yet, so it withholds certainty from everyone at the table and sends them out to decide, or not decide, without it.
