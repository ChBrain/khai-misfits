# Process: Drifting

## Taxonomy

[Right for the Last World](play_right_for_the_last_world.md). The Market's requirement moving away from the shape the structure was built to answer, absorbed case by case at the boundary and never summed.

## Owner

- Project: khai-misfits

## Initiated by

A case arriving that the Rulebook has no clean channel for.
At [the Market](place_the_market.md), the Scout meeting it directly, while the Steward keeps running the Rulebook exactly as written, because nothing inside has told it to run any other way.

## Direction

Toward a gap between the structure and the requirement that grows only where no instrument is built to measure it.
Because every hard case is handled well and closed as an exception, the drifting does not show up as a failure anywhere the structure is watching, so it runs, quietly, in the one place the Scorecard was never built to look: the shape of what is arriving, rather than the count of what got closed.

## Lever

The very competence that handles each hard case well.
Because handling it well is also what keeps it from ever forcing a change to the channel it did not fit, the drifting is driven by good work, not bad, and the lever is that the structure's own diligence at absorbing exceptions is the reason the exceptions never become visible as a pattern.

## Echo

A Backlog one entry heavier, and a Scorecard reading exactly as it read before.
Nothing on the Chart has moved, nothing in the Review room has changed, and the structure is, by every instrument it owns, running as well as it ever has, so what the drifting leaves behind is a widening gap that the place's only trusted proof is structurally unable to report.
