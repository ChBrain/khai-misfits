# Position: Successor

## Taxonomy

[Right for the Last World](play_right_for_the_last_world.md). The seat won by the criteria the hardened structure sets, and answers for holding it the same way.

## Owner

- Project: khai-misfits

## Has

A record built rung by rung against a real, checked criteria.
The standing that comes from having proven the path works, in person.
No authority to have set the criteria, only to have met them.

## Orders

Run the seat the way the seat was run when the running raised you into it.
Answer any challenge to the structure with the record that stands behind the seat.
Train the next rung on the same path that carried this one.

## Loses

The distance to doubt the criteria evenly, exactly because the criteria are what raised it here.
Because the seat's whole standing rests on the path having been the right path, a challenge to the path is a challenge to the standing, so the seat cannot weigh that challenge from the same neutral ground a stranger to the climb could, and the loss is not a fault of character but the plain cost of having climbed honestly.
It ends the run holding a seat it earned fairly, on a path it can no longer be the first to question.

## Drives

Toward a structure defended by the same record that built the career defending it,
right, every time, to point at what actually raised it,
so the seat most invested in the form's soundness is the seat least free to be the one who calls it in doubt.
