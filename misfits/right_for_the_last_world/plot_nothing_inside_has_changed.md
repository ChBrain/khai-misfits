# Plot: Nothing Inside Has Changed

## Taxonomy

[Right for the Last World](play_right_for_the_last_world.md)

## Owner

- Project: khai-misfits

## Cue

[The Market](place_the_market.md), the same channels open, the same rule waiting for the same order, except the order arriving now less often looks like the order the channel was cut for.
Nothing on the Chart different from a year ago, nothing in the Review room that produced the first Scorecard different either.

## Action

[Drifting](process_drifting.md): [The Scout](persona_the_scout.md), holding [Scout](position_scout.md)'s seat, meets a case at the boundary that the Rulebook has no clean channel for, while [The Steward](persona_the_steward.md), holding [Steward](position_steward.md)'s seat, keeps running the Rulebook exactly as written, because nothing has told it to run any other way.

## Stage

[The Scout](persona_the_scout.md), having tabled [Move Before Proof](plan_move_before_proof.md), forces the case through by hand, logs it as one exception among the ordinary run of exceptions, and adds it to [The Backlog](piece_the_backlog.md).
[The Steward](persona_the_steward.md), still on [Hold the Fit](plan_hold_the_fit.md), sees the exception counted and closed, the Rulebook untouched, [The Scorecard](piece_the_scorecard.md) reading exactly as clean as it read the quarter before.

## Tension

The one instrument built to notice a change is the instrument built to absorb it instead.
There is no negligence in the absorbing: an exception handled well is precisely what the Rulebook is for, and handling this one well is the correct, competent response to it in isolation. But the Scorecard was built to count outcomes, not to count the shape of what produced them, so a hundred exceptions handled perfectly well individually can add up to a market that has turned, and the Scorecard, reading each one as a success, has no column for the sum.
