# Position: Steward

## Taxonomy

[Right for the Last World](play_right_for_the_last_world.md). The seat that reads the market's real requirement into a structure, and answers for running that structure faithfully.

## Owner

- Project: khai-misfits

## Has

The authority to write the rule and the channel, and the standing to make either one stick.
A structure that, once built, runs largely on its own account: correctly staffed, it does not need reinventing every quarter.
No authority over the market itself, only over how faithfully its own structure answers what the market asks.

## Orders

Read the requirement, and build the structure it calls for.
Run what is built exactly as written, and train every hand into it.
Trust a clean result as confirmation that the structure is answering correctly.

## Loses

The standing to notice when the requirement has changed, exactly because it was built to answer the requirement as it was.
Because the seat's whole authority rests on the structure it raised, and the structure was tuned to one shape of demand, the seat cannot feel a different shape arrive without an instrument built to read that shape, and it built no such instrument, since none was needed at the time.
It ends the run holding a structure as sound as it has ever been, aimed at a market it has not checked in a long time.

## Drives

Toward a structure run exactly as it was built to be run,
correct in every decision it makes inside the terms it was given,
so the seat that matched the world most precisely is the seat least equipped to notice the world has moved.
