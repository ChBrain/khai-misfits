# Position: Auditor

## Taxonomy

[Right for the Last World](play_right_for_the_last_world.md). The seat that reads what the structure produces, and answers for what gets credited to it.

## Owner

- Project: khai-misfits

## Has

The instrument that turns a quarter's activity into a figure the room can act on.
The standing to say what a result means, not only what it is.
No authority to build the structure itself, only to certify what it returns.

## Orders

Read the results, and credit them honestly to whatever produced them.
Write a credited read into the criteria the place is run and promoted by.
Keep the instrument consistent, so this quarter's figure means what last quarter's meant.

## Loses

The capacity to ask a question its own instrument was never built to answer, exactly because the instrument is what it has to ask with.
Because the Scorecard was raised by the same structure it now measures, the seat cannot use it to test whether that structure still fits, only whether the structure is still running as designed, so the seat loses the one check that would matter most, precisely by being scrupulous with the check it has.
It ends the run with a record it can defend line by line, and no line in it that says what the record was never asked to say.

## Drives

Toward a figure that is honest on its own terms and silent on every other,
correct about what the structure produced and unable to say whether producing it still answers anything,
so the seat most responsible for proof is the seat least able to supply the one proof that would matter now.
