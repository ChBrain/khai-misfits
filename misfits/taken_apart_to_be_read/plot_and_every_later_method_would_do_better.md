# Plot: And Every Later Method Would Do Better

## Taxonomy

[Taken Apart to Be Read](play_taken_apart_to_be_read.md)

## Owner

- Project: khai-misfits

## Cue

A laboratory that reads sediment for the DNA of everything that crossed it, and a site dug in 1974.

## Action

[The Later Hand](persona_the_later_hand.md), holding [Later Hand](position_later_hand.md), reads the report, asks for the soil, and is told it was backfilled.

## Stage

More available now from the same ground than anybody could have got then, and no ground.

## Tension

[The Method Not Yet Invented](piece_the_method_not_yet_invented.md) is certain to arrive and unknowable in content, which makes the case for waiting correct and unbounded.
Every decade has read the same earth better than the last, so the claim that later hands do better is the plainest induction the discipline has rather than optimism. And it never expires: no seat can say the methods are now good enough, because the identical argument is available to every seat after it. So this is not a mistake made in 1974 that better judgement would have avoided, since the same reasoning condemns any excavation whatever, including the ones being funded this year.
