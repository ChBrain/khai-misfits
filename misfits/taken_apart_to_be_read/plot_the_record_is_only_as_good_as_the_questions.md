# Plot: The Record Is Only As Good As the Questions

## Taxonomy

[Taken Apart to Be Read](play_taken_apart_to_be_read.md)

## Owner

- Project: khai-misfits

## Cue

An archive properly deposited, and a report that is faultless.

## Action

[Recording what is removed](process_recording_what_is_removed.md): [the recorder](persona_the_recorder.md), holding [Recorder](position_recorder.md), produces [the site report](piece_the_site_report.md) against the list this decade knows to ask.

## Stage

A substitute for the site, complete in the terms that were current.

## Tension

The record's completeness is with respect to a question set rather than to the ground, and no care closes that.
Nobody sampled for pollen before pollen could be read, nobody sieved for fish bone before anybody wondered what people ate, and nobody kept sediment before it could be read for the DNA of what crossed it. Completeness here would have to have been completeness about questions not yet asked, which is not a standard anybody could meet. So the object that makes the destruction acceptable is itself dated at the moment it is made, and it is the only thing that will exist.
