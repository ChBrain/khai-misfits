# Plan: Find the Rule

## Taxonomy

A **standing plan**: the intent of [the broker's seat](position_broker.md), inside [The Price Neither Will Name](play_the_price_neither_will_name.md).

## Owner

- Owner: [Broker](position_broker.md)

## Direction

Build a rule that clears every trade the values warrant, that both parties join willingly, that makes honest reporting their best reply, and that pays for itself. Design for the truth, since the revelation principle says any rule the parties would game reduces to a truthful one, and then see what the truth costs: to make each side admit its value, the rule must leave it a rent, and the question is whether the gain can cover both rents at once.

## Orders

([The Broker](persona_the_broker.md) runs [Clearing](process_clearing.md) at [the Clearing](place_the_clearing.md), designing for honest reports and conceding [the Rent](piece_the_rent.md) each side needs to reveal, rule after rule.)

## Implementation

([The Clearing](place_the_clearing.md) is where the rule is run; [Clearing](process_clearing.md) applies the revelation principle and finds that on the trades near the edge of the overlap the two rents together exceed the gain, so a self-funding rule must let those trades fall and an efficient rule must run a deficit, one of the four properties always giving.)

## Targets

- [ ] a rule is sought that is efficient, voluntary, truthful, and self-funding at once
- [ ] it is designed for truthful reports, by the revelation principle
- [ ] each side must be conceded a rent to make revealing its value the best reply
- [ ] the two rents exceed the gain at the margin, so no rule holds all four and one gives
