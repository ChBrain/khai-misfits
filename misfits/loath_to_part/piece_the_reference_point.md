# Piece: The Reference Point

## Taxonomy

[Loath to Part](play_loath_to_part.md). The ownership baseline (Tversky and Kahneman): the status quo from which gains and losses are measured, so that owning the good makes keeping it the zero and losing it a loss rather than forgoing it a smaller gain.

## Load Bearing

Value is measured not in absolutes but from a reference point, and ownership moves that point to include the good, so parting is a loss and acquiring is a gain, though the good is the same (Tversky and Kahneman). Guard against reading the owner and the buyer as valuing the good differently by taste: it is the reference point, not the preference, that differs.
