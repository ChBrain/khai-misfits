# Persona: The Machine That Wants a Number

## Taxonomy

[Automation](position_automation.md). The ship that steers itself, asking the rule for a value it does not contain.

## Owner

- Project: khai-misfits

## Projection

Not a threat and not a mistake.
A serious attempt to make a rule executable, by people who have read it carefully and want it obeyed more consistently than people obey it.
The best-resourced settlement anybody has proposed.

## Action

Reads the rule.
Implements everything that is precise.
Stops at one word, and asks what it is worth.

## Shadow

That the request is exactly the wrong one and there is no better one available.
An algorithm cannot execute a judgement, so the implementing literature asks for the ambiguity to be removed, which is right about what an algorithm needs and is a request to spend the quantity that was protecting everybody.
It ends demonstrating the structure rather than escaping it.

## Tell

Is still asking about 17.
