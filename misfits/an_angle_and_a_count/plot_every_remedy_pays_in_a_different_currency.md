# Plot: Every Remedy Pays in a Different Currency

## Taxonomy

## Owner

## Cue

## Action

[Smearing the second](process_smearing_the_second.md) is demonstrated by [the operator](persona_the_operator.md); abandonment and separation are put beside it at [the bureau](place_the_bureau.md).

## Stage

A settlement, of a kind, in whichever direction the vote goes.

## Tension

Each remedy is real and each pays somewhere else, so the vote moves the cost and never cancels it.
Stop correcting and the count is clean forever while civil noon walks away from the sun, about a minute a century now and faster later, until somebody has to make a much larger correction than the one being avoided. Smear it and nothing sees a discontinuity, at the price of a second that is briefly not a second and of estates that pick different windows and stop agreeing with each other. Keep two timescales, one for the Earth and one for the machines, and the conversion between them needs a table of corrections that does not exist yet, so the number of seconds between now and a date in the 2030s remains unknowable. And knowing all of this completely, which every party does, still leaves the seat choosing which requirement to break.
