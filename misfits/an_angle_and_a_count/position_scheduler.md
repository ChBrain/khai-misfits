# Position: Scheduler

## Taxonomy

[An Angle and a Count](play_an_angle_and_a_count.md). The seat that treats a difference of times as a duration.

## Owner

- Project: khai-misfits

## Has

Two timestamps, an ordering to maintain, and a timeout to enforce.

## Orders

Subtract. Order. Wait the difference out.

## Loses

Its footing on a count that does not only go up.
Nothing here is an oversight: a measurement that can run backwards is not a measurement, and the seat was built on the definition rather than on an assumption somebody forgot to check.

## Drives

Toward events in the order they happened, using the only marker there is.
