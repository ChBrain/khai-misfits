# Piece: The Obligation Nobody Has

## Taxonomy

[It Was There When I Wrote It](play_it_was_there_when_i_wrote_it.md). The undertaking to keep an address alive, which was never given and never requested.

## Owner

- Project: khai-misfits

## Place

Absent, between [the footnote](place_the_footnote.md) and [the server](place_the_server.md).
Not withheld by anybody: simply never created.

## Load Bearing

Without it the host is negligent and the remedy is a policy.
It is load bearing because the duty is **absent rather than breached**: there is no standard the host falls short of, nothing an auditor would find, and no rule that would have caught it, so the failure sits outside conduct entirely.

## Apparent

Not a thing at all, like every absent obligation.
It reads as the natural state of the web rather than as a missing commitment, which is exactly why nobody notices that an entire citation apparatus was built on top of it.

## Yearbook

Never created by anyone; relied upon by everyone who cites.
A host that wished to honour it could not, since it does not learn who has cited it.
