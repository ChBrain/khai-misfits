# Plot: Exactly Where It Is

## Taxonomy

[It Was There When I Wrote It](play_it_was_there_when_i_wrote_it.md)

## Owner

- Project: khai-misfits

## Cue

[The Footnote](place_the_footnote.md), being written.
[The Address](piece_the_address.md), checked and recorded.

## Action

[Citing](process_citing.md): [The Citation](persona_the_citation.md), in [the cited seat](position_cited.md), records author, title, date and address at [the footnote](place_the_footnote.md), having read the source.

## Stage

[The Citation](persona_the_citation.md), on [Say Exactly Where It Is](plan_say_exactly_where_it_is.md), represents the source accurately and gives the only handle the thing had.

## Tension

The scholarship is good, and the play has to establish that before it can be the problem.
The source was read. It said what the author said it said. The reference is precise, it was checked at the time, and it is honest. **There is no carelessness here to find**, and no better practice was available, because an address was the only way to say where the thing was.
So the trap cannot be sprung by improving the citation. It has to be sprung with a reference that is exact, honest, verified, and correctly formed, doing the one thing a citation can do: fixing a location rather than a thing.
