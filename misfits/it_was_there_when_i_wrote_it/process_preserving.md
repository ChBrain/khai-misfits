# Process: Preserving

## Taxonomy

[It Was There When I Wrote It](play_it_was_there_when_i_wrote_it.md). A copy taken as the citation is made, and served in place of the original address.

## Owner

- Project: khai-misfits

## Initiated by

[The moment of citing](piece_the_moment_of_citing.md), and only that moment.
By institutions and libraries that run it.

## Direction

Toward a reference that survives the loss of its target, which it achieves completely.
This is not a proposal and there is no scepticism to register about whether it works: a citation to a preserved copy resolves after the original is gone.
Its condition is timing, because once the target has gone there is nothing left to copy.

## Lever

A copy, taken while the thing still exists.
Because no later diligence recovers a target that has already vanished, this step reaches everything future and nothing past.

## Echo

Every reference made from now on, secured,
and the corpus already written, exactly as it is.
