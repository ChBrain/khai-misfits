# Position: Cited

## Taxonomy

[It Was There When I Wrote It](play_it_was_there_when_i_wrote_it.md). The reference's seat: exact, checked, honest, and able to fix only a location.

## Owner

- Project: khai-misfits

## Has

A source read and accurately represented.
An address, which is the only handle the thing had.
Verification at the time of writing.

## Orders

Name the author, the title, the date and the address.
Check before recording.
Fix the location.

## Loses

Nothing done wrong and nothing improvable, which is what makes this seat impossible to fix.
Because a citation can only fix an address, and what sits at that address is kept by somebody else under no obligation, the accuracy of this seat is irrelevant to whether it will still work in ten years.
It ends perfectly formed and pointing at nothing.

## Drives

Toward saying exactly where a thing is,
which is all a reference can ever do,
so the seat that does its job completely is the seat that fails silently.
