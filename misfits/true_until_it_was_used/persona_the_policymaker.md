# Persona: The Policymaker

## Taxonomy

[Policymaker](position_policymaker.md). The one who must decide, on something.

## Owner

- Project: khai-misfits

## Projection

A decision that cannot wait, and the best account anybody has of how the economy behaves.
No model that was estimated anywhere but under a regime.

## Action

Reads the relation. Acts on it.
Changes the arrangement in doing so.

## Shadow

Cannot decline to use a model, because declining is choosing by a worse one.
There is no unconditioned account available: every estimate of how an economy behaves is estimated from a period in which some arrangement was in force, so the seat's choice is between a model with the property and a guess without one, and it takes the model, correctly.

## Tell

Uses the best instrument there is, and the use is what disarms it.
