# Place: The Edge

## Taxonomy

[Too Kind to Drop](play_too_kind_to_drop.md). The last-mile gateway, the home router or modem where deep buffers classically ship by default, where [the Keeper](persona_the_keeper.md) holds [The Buffer](piece_the_buffer.md) and where [the Manager](persona_the_manager.md) can intervene. Hosts [The Cheap Memory](plot_the_cheap_memory.md) and [The Early Drop](plot_the_early_drop.md).

## Owner

- Project: khai-misfits

## Shown

A small consumer device, memory sized in the megabytes at a cost of pennies, sitting between a fast local network and a slower uplink. The case for building it deep looks unarguable from here: capacity that would otherwise sit idle, spent instead on not throwing packets away.

## Holds

[The Buffer](piece_the_buffer.md) itself, sized on [Never Drop](plan_never_drop.md) by [the Keeper](persona_the_keeper.md), memory bought cheap and defaulted deep. Where [the Manager](persona_the_manager.md) is present, the same memory kept but bounded on [Drop Early](plan_drop_early.md), no longer let to fill unwatched.

## Offers

Room, and nothing else: capacity to hold a burst that would otherwise be dropped, offered before any packet has arrived to need it, "too kind to drop" the standing discipline the memory is built to.

## Withheld

Any distinction between a burst worth absorbing and a queue that will never drain. The Edge, stocked by [the Keeper](persona_the_keeper.md), cannot tell the two apart on its own; only [Culling](process_culling.md), run by [the Manager](persona_the_manager.md), reads the queue closely enough to draw that line, and where no manager sits at the Edge, none is drawn.
