# Plan: Never Drop

## Taxonomy

A **standing plan**: the intent of [the keeper's seat](position_keeper.md), inside [Too Kind to Drop](play_too_kind_to_drop.md).

## Owner

- Owner: [Keeper](position_keeper.md)

## Direction

Hold every packet that arrives faster than the link can send it, and make the memory deep enough that a discard need never happen, because a dropped packet looks like thrown-away work and memory is cheap. Spare the loss without exception, counting each packet kept as waste avoided, even the losses the sender was waiting to see.

## Orders

([The Keeper](persona_the_keeper.md) holds [the Buffer](piece_the_buffer.md) through [Hiding](process_hiding.md), absorbing the packets that should have been dropped so [the Signal](piece_the_signal.md) never travels [the Loop](place_the_loop.md), leaving [the Concealment](piece_the_concealment.md).)

## Implementation

([The Edge](place_the_edge.md) ships with memory enough to spare; the [hiding](process_hiding.md) process holds the losses the sender reads as its signal, so [the Buffer](piece_the_buffer.md) fills to the top and stands full, its depth the same generosity that would absorb a passing burst turned into the wall a standing flood cannot cross.)

## Targets

- [ ] every packet is held rather than dropped, the memory made deep enough that a discard need never happen
- [ ] the loss is spared without exception, each kept packet counted as waste avoided
- [ ] the spared loss is the sender's only signal, so sparing it withholds the road
- [ ] the deep buffer fills and stands full, the burst-absorbing virtue and the signal-hiding defect the same depth
