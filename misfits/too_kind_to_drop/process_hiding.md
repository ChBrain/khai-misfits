# Process: Hiding

## Taxonomy

[Too Kind to Drop](play_too_kind_to_drop.md). Run by [the Keeper](persona_the_keeper.md) on [Never Drop](plan_never_drop.md), at [The Loop](place_the_loop.md), inside [The Swallowed Signal](plot_the_swallowed_signal.md).

## Owner

- Project: khai-misfits

## Initiated by

Room left in [The Buffer](piece_the_buffer.md): as long as there is memory to spend, [the Keeper](persona_the_keeper.md) holds every arriving packet rather than drop it, the standing discipline the buffer was built to carry out.

## Direction

Toward silence, not toward loss: each packet the Keeper holds instead of drops is a packet that never reports the queue growing, so the more faithfully Never Drop is kept, the less of what is happening inside the buffer ever crosses [The Loop](place_the_loop.md) back to [the Sender](persona_the_sender.md).

## Lever

An oversized buffer absorbing the loss-and-delay signal that congestion control depends on to back off (Gettys and Nichols): the mechanism is not that the signal is amplified or diverted, it is concealed, present in principle and withheld in fact, so the sender reads a clean channel where a filling one is.

## Echo

[The Concealment](piece_the_concealment.md): a sender with nothing to slow it down, licensed by silence to keep [Filling](process_filling.md), and a buffer that, having refused every earlier drop, is left with only [Bloating](process_bloating.md) to carry the pressure it never let escape.
