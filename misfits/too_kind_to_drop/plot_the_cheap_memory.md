# Plot: The Cheap Memory

## Taxonomy

[Too Kind to Drop](play_too_kind_to_drop.md)

## Owner

- Project: khai-misfits

## Cue

[The Edge](place_the_edge.md), the gateway before the bottleneck link, memory now cheap enough to spend without counting it, and a dropped packet still reading as pure waste.

## Action

[The Keeper](persona_the_keeper.md), holding [the keeper's seat](position_keeper.md), on [Never Drop](plan_never_drop.md), stocks [The Buffer](piece_the_buffer.md) deep, sized well past any burst it is likely to meet.

## Stage

Memory costs almost nothing now, and a lost packet still looks like the one failure worth spending against, so a deeper buffer only ever reads as safer, never as a cost to weigh. The Keeper fits the gateway with room enough to hold seconds of traffic at line rate, and every packet that would once have been dropped now has somewhere to sit. No burst has yet arrived to fill it, no flow has yet leaned on it; the choice is locally sound by every measure anyone would think to check.

## Tension

The Buffer stands ready, oversized against the burst it was built to absorb, its depth untested by a sender that will not stop asking. The size chosen to spare a small, cheap loss carries a debt nobody has named yet, and nothing here is wrong: the debt will only show once something fills it and finds no reason to stop.
