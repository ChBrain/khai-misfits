# Persona: The Keeper

## Taxonomy

[Keeper](position_keeper.md). The queue discipline of the deep buffer, which holds every packet rather than drop one, sized generous because memory is cheap and a discarded packet looks like waste, and in holding the loss it hides the signal.

## Owner

- Project: khai-misfits

## Projection

Careful, generous, sparing of nothing.
Is the buffer's own rule: when packets arrive faster than the link can send them, hold them, all of them, rather than throw any away, and make the memory deep enough that a drop need never happen.
No fault in the instinct: a burst held and passed is a burst saved, and for a burst that is exactly what a buffer is for, so keeping every packet reads as plain good husbandry.

## Action

Holds [the Buffer](piece_the_buffer.md) on [Never Drop](plan_never_drop.md), through [Hiding](process_hiding.md) at [the Edge](place_the_edge.md), absorbing the packets that should have been lost so [the Signal](piece_the_signal.md) never travels [the Loop](place_the_loop.md) back to the Sender.
Cannot pass what it will not drop: the only way the sender is told to slow is a loss, and the Keeper's whole discipline is to prevent losses, so [the Concealment](piece_the_concealment.md) is not a failure of the rule but the rule working perfectly.
Does what a deep buffer does with a flood it is too generous to shed: it takes it all in, fills to the top, and holds there, a standing queue instead of a passing one.

## Shadow

Not a hoarder and not a fool: the Keeper is doing the thing buffers are praised for, sparing packets and keeping the link fed, and its generosity is the same generosity that absorbs a genuine burst and drains.
Because the loss it spares is the signal the sender needs, the Keeper's kindness is exactly what starves the feedback loop, so the deeper and more sparing the buffer the more completely it hides the road, the virtue and the defect the same depth measured against a burst or against a standing flood.
It is too kind to drop, and being too kind to drop is precisely the trap.

## Tell

Says it threw nothing away, held every packet, lost not one, and means it as a credit.
Cannot see that the very drops it prevented were the words the sender was waiting for, so its full, generous buffer stands as a wall the signal cannot cross, and the queue behind it never drains.
