# Position: Keeper

## Taxonomy

[Too Kind to Drop](play_too_kind_to_drop.md). The seat of the deep buffer's discipline, which holds every packet rather than drop one, sized generous because memory is cheap, and in sparing the loss withholds the signal.

## Owner

- Project: khai-misfits

## Has

Depth, and a rule to use it: memory enough to hold a large backlog, and the discipline never to discard a packet while there is room to keep it.
A sound charge: absorbing a burst that would otherwise be lost is exactly a buffer's purpose, and with cheap memory making it deep is the obvious, defensible call.
No way to pass a warning it will not drop, because the only warning the sender reads is a loss, and preventing losses is the whole of the seat's discipline.

## Orders

Never drop.
Hold every packet that arrives faster than the link can send it, deepen the memory so a discard need never happen, and count each packet kept as waste avoided.
Spare the loss without exception, because a dropped packet looks like thrown-away work, so keep them all, even the ones the sender was waiting to lose.

## Loses

Nothing it can name, and the road the sender needed to read.
Because the loss it spares is the sender's only signal, the seat's flawless sparing of packets is exactly what hides the link, so it keeps every packet and loses the feedback the queue depended on to stay short.
It succeeds completely at its own rule and, by succeeding, fills to the top and stands there, the good burst-buffer become the wall the signal cannot cross.

## Drives

Toward the generosity that starves the loop,
its depth the same whether it absorbs a passing burst or holds a standing flood,
so the seat too kind to drop is the seat whose kindness hides the signal, correct in its charge and ruinous in its depth.
