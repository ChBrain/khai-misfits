# Persona: The Holder

## Taxonomy

[Holder](position_holder.md). The lowest-ranked work, which reached the shared resource first and took it as it was entitled to, and which needs only a little time to finish and release, but is set down mid-task still holding it.

## Owner

- Project: khai-misfits

## Projection

Lowest priority, and doing nothing wrong.
Is the ordinary background work that got to the resource first and took the lock, permitted to, with only a short task to complete before letting go.
No greed in it and no delay of its own choosing: it wants to finish and release, and would, in a moment, if only it were left to run.

## Action

Takes [the Lock](piece_the_lock.md) on [Hold and Release](plan_hold_and_release.md) inside [the Critical Section](place_the_critical_section.md), and means to finish and release.
Cannot resist [Preempting](process_preempting.md): when a higher-ranked task becomes ready, the Holder is set down mid-task by the same rule that governs everything, still holding the lock, because a task cannot both be preempted and go on running.
Does what the lowest work does when outranked: it stops where it is, and what it is holding it holds still, frozen, until the machine comes back to it.

## Shadow

Not a laggard and not a hoarder: the Holder is quick with the lock and would release it on time if the machine let it run, and it did nothing to earn the freeze but exist at low rank while holding a shared thing.
Because it holds what the highest work needs and yet ranks below the middle work that preempts it, the Holder becomes the still point the whole inversion turns on, blameless and load-bearing at once, the lowest work standing in for the highest and unable to move for the middle.
Its fault, if the word applied, would only be that it was low and holding, and neither of those is a fault.

## Tell

Says it will be done in a moment, and would be, if it ran.
Cannot finish while a higher task is ready, so it sits frozen mid-section with the lock in hand, the release the whole system is waiting on suspended not by anything it did but by a rule correctly applied to it.
