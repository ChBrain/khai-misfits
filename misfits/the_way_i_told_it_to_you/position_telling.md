# Position: Telling

## Taxonomy

[The Way I Told It to You](play_the_way_i_told_it_to_you.md). The seat where an event that happened to one person is put into words for another.

## Owner

- Project: khai-misfits

## Has

Everything that happened, in the only copy there is.
A listener, present, particular, and known.
A wide latitude over which true things to say and in what order.

## Orders

Describe the afternoon so that this person ends up holding it.
Use what they already know, because that is what reference runs on.
Stop when they have it.

## Loses

The latitude, on the way out, and does not notice.
**Every description this seat can offer is a description of the same afternoon**, so the seat is never once
choosing between honesty and its opposite, and nothing in the work of it flags the moment where the copy
begins to be edited.

## Drives

Toward an account that a particular person can take whole,
built out of things that are true and selected because they will land,
which is what a competent speaker does and what leaves this seat holding one version of five.
