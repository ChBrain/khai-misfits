# Plan: Tell Them Which One Is Best

## Taxonomy

A **mandate**: the intent of [the evaluation seat](position_evaluation.md), inside [The One Everybody Used](play_the_one_everybody_used.md).

## Owner

- Owner: [Evaluation](position_evaluation.md)

## Direction

Examine, score, test and publish, so that a breeder reads results rather than reputation. Extend the panel whenever a new variant is characterised, because that is what reducing inherited disease consists of.

## Orders

([The Health Scheme](persona_the_health_scheme.md) examines, scores, tests, records, publishes, and improves, each improvement making the best animal easier to identify.)

## Implementation

([The Ring](place_the_ring.md), where merit is settled publicly; the [publishing](process_publishing.md) process producing [the published result](piece_the_published_result.md); read simultaneously by everybody, which starts [converging](process_converging.md).)

## Targets

- [ ] the machinery is sound and it does reduce inherited disease
- [ ] results are published so that any breeder can read them
- [ ] each improvement sharpens the answer to which animal is the best bet
- [ ] a sharper answer is a narrower one, and the seat has no version that informs without discriminating
