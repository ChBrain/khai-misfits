# Place: The Ring

## Taxonomy

[The One Everybody Used](play_the_one_everybody_used.md). Where merit is settled in public and published, so that everybody reads the same answer at the same time.

## Owner

- Project: khai-misfits

## Shown

Scores, certificates, panel results, placings and progeny records, available to anybody.
A hundred breeders consulting them, separately.

## Holds

The convergence, and the reason it requires no copying.
It holds the play's sharpest point: the breeders do not need to watch each other, because the evidence is public and correct, so independent reading produces the same answer as imitation would and produces it faster.

## Offers

An honest, public, checkable account of which animal is the best bet, which is exactly what a breed health programme is meant to supply.

## Withheld

Any indication of the aggregate.
Nothing here tells a breeder how many others have read the same page and reached the same conclusion, so the concentration is invisible from every seat that contributes to it.
