# Process: Closing

## Taxonomy

[The One Everybody Used](play_the_one_everybody_used.md). A register admitting only recorded descent, which defines the breed and seals the pool.

## Owner

- Project: khai-misfits

## Initiated by

The wish to certify what an animal is descended from.
At [the register](place_the_register.md), as the founding rule.

## Direction

Toward a verifiable pedigree, which is the whole point.
This is not a restriction anybody imposed on the breed: it is what the word breed means in a register, so a scheme admitting outside animals would not be a laxer register but a different kind of document.
And it makes the population closed, so variation can be redistributed inside it and cannot be replenished, whatever anybody does.

## Lever

The definition itself, which is not adjustable.
Because the closure is constitutive rather than regulatory, there is nothing here to relax and no lever that leaves the function intact.

## Echo

A breed, and a pool that can only get narrower.
Everything after this is a question of how fast.
