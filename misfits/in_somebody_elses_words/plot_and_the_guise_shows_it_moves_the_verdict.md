# Plot: And the Guise Shows It Moves the Verdict

## Taxonomy

[In Somebody Else's Words](play_in_somebody_elses_words.md)

## Owner

- Project: khai-misfits

## Cue

A question about whether any of this actually changes what anybody concludes.

## Action

[Running the guise](process_running_the_guise.md): [the researcher](persona_the_researcher.md), holding [Researcher](position_researcher.md), holds content fixed, varies only the pragmatic layer, and measures the ratings.

## Stage

A measured shift in how a witness is rated, produced by style alone.

## Tension

The demonstration establishes the effect and rules out the only clean repair.
Holding content constant and varying hedging, hesitation, politeness and length moves how listeners rate a witness on competence and trustworthiness, which takes this from a plausible worry to a shown one. The same result closes the obvious fix: if style always moves the rating, there is no styleless rendering to fall back on, so the remedy cannot be to strip the layer out.
