## Action

## Stage

## Tension

Neither duty is the wrong one, and that is what puts the failure outside the profession's conduct.
An interpreter licensed to summarise would be deciding the case; one licensed to advocate would be a party. The code that demands accuracy and invisibility is the code anybody would write, and the training behind it is real. What follows is not a criticism of either requirement but a fact about sentences.
