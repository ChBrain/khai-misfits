# Persona: The One That Answered First

## Taxonomy

[Memory](position_memory.md). A memory lineage made thirty years ago, still specific, still fast, and still right about what it was made for.

## Owner

- Project: khai-misfits

## Projection

Reliable, quick and correct.
Has answered every version of this pathogen the host has met since, and answered them well.
Would be the reason a second infection is milder, in every case but this one.

## Action

Sees the conserved parts.
Proliferates.
Puts antibody in the blood within three days.

## Shadow

That doing exactly this is what goes wrong.
**Speed is not being traded against accuracy here**, because the response is accurate about everything it
binds; it is simply that binding the unchanged parts of an escaped strain neutralises nothing, and doing it
first is what removes the material somebody else needed.

## Tell

Is the element the host would be worse off without.
Is the element that made the better answer impossible.
