# Persona: The Strain That Drifted

## Taxonomy

[Encounter](position_encounter.md). This year's version, mostly the same and changed where it mattered.

## Owner

- Project: khai-misfits

## Projection

Unremarkable, ordinary and not new.
Descended from the strain the host already knows, by the usual amount, in the usual places.
Would be handled by the existing memory if it had changed anywhere else.

## Action

Arrives.
Presents a surface that is largely the old one.
Escapes at the sites the old antibody was aimed at.

## Shadow

That none of this is aimed at anybody.
**Drift is not evasion**: change accumulates at the sites under selection whether or not any particular
host has a memory, and the same strain would have arisen in a population that had never seen its ancestor.

## Tell

Is the only element that changed.
Is the element that changed for reasons having nothing to do with the host it meets.
