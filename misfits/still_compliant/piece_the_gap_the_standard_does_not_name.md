# Piece: The Gap the Standard Does Not Name

## Taxonomy

[Still Compliant](play_still_compliant.md). The distance between a fixed text and a moving hazard, opened by nobody and found by no audit.

## Owner

## Place

Everywhere the framework is silent, at all times, through [ageing](process_ageing.md).
Absent from [the board paper](place_the_board_paper.md) and from [the attestation](place_the_attestation.md), which are both comparisons with the list.

## Load Bearing

Without it the play is only about spending less, which What Everyone Else Does already holds.
It is load bearing because **a standard is a document and a hazard is a process**: custom cannot age
relative to practice, since it is practice, but a text can be years behind and still confer the defence, and
improvement by the whole field moves it not at all.

## Apparent

That somebody in the firm must be able to see it.
An audit is a comparison with the list, so a thing the list does not name is not a finding. Seeing it
requires somebody paid to look past the list, and the seat that would fund that is the seat that stopped at
the line.

## Yearbook

The interval between revisions of any published standard, set by the body that maintains it, against an
adversary consulting no publication cycle at all.
