# Process: Conforming

## Taxonomy

[Still Compliant](play_still_compliant.md). Mapping a programme onto a control list until every item is answered.

## Owner

- Project: khai-misfits

## Initiated by

A named framework and a firm that intends to be defended.
At [the attestation](place_the_attestation.md), each cycle, by people doing careful work.

## Direction

Toward complete coverage of the list.
The list is good, so this is not a formality: a firm that conforms to it is doing most of what a competent
programme would do, and would be right to conform to it if no statute mentioned it.

## Lever

Completeness against the text, which is the quantity that is measured and the only one that is.

## Echo

Every control answered,
a mapping an auditor would pass,
and a boundary where a description used to be.
