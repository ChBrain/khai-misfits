## Cue

A question from a later decade, at the catalogue.

## Action

[Asking the record](process_asking_the_record.md): [the latecomer](persona_the_latecomer.md), holding [Latecomer](position_latecomer.md), searches [the finding aid](piece_the_finding_aid.md) at [the reading room](place_the_reading_room.md) and finds almost nothing.

## Stage

A sound conclusion, drawn correctly, from a record that was shaped to answer somebody else.

## Tension

An absence and a removal return the same result, and the building holds nothing that separates them.
A catalogue is a list of what is there and can never be a list of what is not, because a description of a destroyed record would have been the record. So the empty search reads as the practice having been rare, the group small, or the matter simply not written down, and every one of those is a finding somebody will publish. The reading that it was appraised away is available only as a suspicion, and it is a suspicion no source in the building can settle, which is why the error does not accumulate into a correction the way ordinary errors do.
