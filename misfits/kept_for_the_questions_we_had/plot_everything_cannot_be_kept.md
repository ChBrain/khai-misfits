# Plot: Everything Cannot Be Kept

## Taxonomy

[Kept for the Questions We Had](play_kept_for_the_questions_we_had.md)

## Owner

- Project: khai-misfits

## Cue

An intake larger than the hours available to describe it.

## Action

[Describing what is kept](process_describing_what_is_kept.md): [the cataloguer](persona_the_cataloguer.md), holding [Cataloguer](position_cataloguer.md), works through a backlog that grows faster than the rate.

## Stage

Shelving that is affordable, and description that is not.

## Tension

The obvious exit closes before the play begins, and it closes on a cost nobody expects.
Keeping everything sounds like the cautious option and is not, because the binding constraint is skilled description rather than space: an accession nobody has arranged cannot be asked for, so it is not in the archive in any sense a researcher can use. A larger undescribed record therefore answers fewer questions than a smaller described one, which means selecting is not a concession to budget. It is the thing that makes an archive an archive.
