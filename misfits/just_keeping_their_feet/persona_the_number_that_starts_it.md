# Persona: The Number That Starts It

## Taxonomy

[Number That Starts It](position_number_that_starts_it.md). The crowd size below which nothing exists to be found.

## Owner

- Project: khai-misfits

## Projection

A threshold in the number of people on a span, below which the structure's damping absorbs everything the walkers give it.
Not a load figure, not a stress, and not on any drawing.

## Action

Holds the deck perfectly still for every test, walk-through and inspection anybody performs.
Gives way on the first day the bridge is busy.

## Shadow

Hides the phenomenon behind the very procedures meant to find it.
Testing is done with the people available, which is never a crowd, so the structure passes every trial honestly and the failure mode is not concealed by anybody: it does not exist at the scales at which things are checked, and the first occasion it exists is the first occasion it matters.

## Tell

Makes the bridge blameless on every test and wrong on the day it opens.
