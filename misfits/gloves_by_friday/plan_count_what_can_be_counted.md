# Plan: Count What Can Be Counted

## Taxonomy

A **mandate**: the intent of [the verifier's seat](position_verifier.md), inside [Gloves by Friday](play_gloves_by_friday.md).

## Owner

- Owner: [Verifier](position_verifier.md)

## Direction

Confirm that what was recorded as done was done, using the evidence the action produced. Require the artefact, because requiring it is what keeps the record honest, and accept that no artefact exists for a hazard nobody introduced.

## Orders

([The Auditor](persona_the_auditor.md) verifies issue sheets, dated procedures and attendance registers, records the corrective action complete, and has no method by which an absence could be confirmed.)

## Implementation

([The Action Log](place_the_action_log.md), verified line by line; the asymmetry that the lower rungs generate documents and the upper ones generate absences; the distribution coming out as [the tally](piece_the_tally.md).)

## Targets

- [ ] every implemented measure is checked against the evidence it produced
- [ ] the lower rungs verify cleanly, because they leave signatures and registers
- [ ] the upper rungs cannot be verified the same way, because absences leave no document
- [ ] the corrective action closes as complete, truthfully, without reference to the hazard
