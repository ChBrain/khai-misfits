# Plan: Be Seen to Have Answered

## Taxonomy

A **mandate**: the intent of [the principal's seat](position_principal.md), inside [Gloves by Friday](play_gloves_by_friday.md).

## Owner

- Owner: [Principal](position_principal.md)

## Direction

Ask what has been done about Tuesday, and ask it before the end of the week, because an organisation that asks slowly is a worse one. Accept a real, approved, implemented corrective action, and close the item.

## Orders

([The Board](persona_the_board.md) requires a visible answer on the incident's timescale, which is the correct thing to require, and in doing so sets the window inside which only the lower rungs can be delivered.)

## Implementation

([The Action Log](place_the_action_log.md), where the answer must appear; the deadline running against [the lead time](piece_the_lead_time.md) of each rung; capital released on a cycle that cannot be convened inside it.)

## Targets

- [ ] the question is asked promptly and legitimately
- [ ] the deadline in it is set by the incident and not by the engineering
- [ ] the window excludes every rung that requires a design change or a shutdown
- [ ] a true answer is given and accepted, naming the weakest control on the list
