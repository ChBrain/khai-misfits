# Persona: The Compaction

## Taxonomy

[Interruption](position_interruption.md). The correct and necessary work that makes a machine slow for a moment: reclaiming, rebuilding, compacting, yielding.

## Owner

- Project: khai-misfits

## Projection

Deliberate, designed and beneficial.
Uses very little on average, and takes a few milliseconds to tens of milliseconds when it runs.
Not a leak, not a bug and not an oversight: a thing an engineer chose and would choose again.

## Action

Runs, when it is due.
Occupies the machine briefly.
Leaves it in a better state than it found it.

## Shadow

Nothing, and the seat is what removes the last place to point: the slow moment is not a failure but maintenance, contention or power management, so there is no defect to eliminate and eliminating the activity would cost more than the pause does.
Because such activities are many and independent across a fleet, the chance that some machine is busy at any instant rises with the number of machines rather than falling with the quality of any of them.
It ends having improved the machine and lengthened a request.

## Tell

Says nothing, being a scheduled task.
Its whole statement is a few milliseconds of a graph, in a place nobody was looking.
