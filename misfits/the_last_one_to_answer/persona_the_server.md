# Persona: The Server

## Taxonomy

[Component](position_component.md). One machine of many, fast almost always, and occasionally busy with something it was built to do.

## Owner

- Project: khai-misfits

## Projection

Well provisioned, correctly configured and meeting its target.
Answers in about ten milliseconds, ninety-nine times in a hundred, which is a figure most systems would be pleased with.
Not marginal, not overloaded and not neglected.

## Action

Receives a call and answers it.
Occasionally takes a second instead, because memory is being reclaimed or a log compacted or a neighbour wants the cache.
Returns a correct answer either way.

## Shadow

Nothing, and the seat is where the play's innocence is established: there is no defect here to remove, no threshold it fails, and replacing it with a better machine of the same kind changes the rate and not the structure.
Because its slow case is correct work rather than a fault, no amount of engineering attention converts this seat into one that is never slow.
It ends having met its target and having contributed to a service that did not.

## Tell

Says: ten milliseconds, ninety-ninth percentile one second.
Which is a good server, and is the whole of the problem.
