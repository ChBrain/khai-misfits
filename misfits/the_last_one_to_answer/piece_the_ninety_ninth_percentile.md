# Piece: The Ninety-Ninth Percentile

## Taxonomy

[The Last One to Answer](play_the_last_one_to_answer.md). One call in a hundred taking a second where the typical call takes ten milliseconds.

## Owner

- Project: khai-misfits

## Place

Measured at [the fleet](place_the_fleet.md), per machine.
Answered nowhere: the slow case is correct work rather than a fault.

## Load Bearing

Without it every component is uniformly fast and there is no play.
It is load bearing because it is **a good figure rather than a bad one**: a machine that is fast ninety-nine times in a hundred is a machine most systems would accept, so the play's cause is assembled out of components that pass every test anybody would set them.

## Apparent

A tail on a histogram, of the ordinary kind.
It reads as the small residue of imperfection that every system has, and the fact that a small residue is exactly what the fan-out is about to multiply does not appear in it.
