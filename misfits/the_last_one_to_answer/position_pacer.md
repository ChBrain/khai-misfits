# Position: Pacer

## Taxonomy

[The Last One to Answer](play_the_last_one_to_answer.md). The seat occupied on each occasion by whichever reply happens to arrive last.

## Owner

- Project: khai-misfits

## Has

An answer as correct and complete as any other.
A delay that would be unremarkable in isolation.
No identity: a different machine each time, unknowable in advance.

## Orders

Arrive last.
Set the response time of the whole request.
Become indistinguishable from the others afterwards.

## Loses

Nothing, and the seat is why the harm has no address: the pacing machine is not a bad machine, is not the same one twice, and did nothing the others would not do eventually.
Because the occupant changes on every occasion, there is no component to fix, replace or hold responsible for a service that is reliably slow.
It ends having decided the outcome and leaving no trace as a cause.

## Drives

Toward answering correctly,
never once identifiable in advance,
so the seat that governs everything is the one that cannot be found.
