# Piece: The Tail

## Taxonomy

[The Last One to Answer](play_the_last_one_to_answer.md). The part of the service's distribution where nearly two requests in three now live, and which no mean reports.

## Owner

- Project: khai-misfits

## Place

At [the dashboard](place_the_dashboard.md), present and unshown.
Answered only by [hedging](process_hedging.md), and only by covering it.

## Load Bearing

Without it the harm is a statistic rather than an experience.
It is load bearing because it is **where the service actually is**: the typical user request is now the slow kind, so the tail has stopped being a tail of the service even while it is still a tail of every component in it.

## Apparent

An edge case, by its name.
It reads as the unusual end of a distribution, which it is per machine and is not per request, and the word itself is what keeps it sounding rare.
