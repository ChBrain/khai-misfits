# Plot: Nothing Went Wrong Anywhere

## Taxonomy

[The Last One to Answer](play_the_last_one_to_answer.md)

## Owner

- Project: khai-misfits

## Cue

The reason a machine was slow that once.
[The Legitimate Pause](piece_the_legitimate_pause.md), running as scheduled.

## Action

[Answering](process_answering.md), examined: [The Compaction](persona_the_compaction.md), in [the interruption seat](position_interruption.md), occupies the machine and leaves it better.

## Stage

[The Compaction](persona_the_compaction.md), on [Do the Necessary Work Now](plan_do_the_necessary_work_now.md), reclaims memory, compacts a log, rebuilds data, yields a shared cache, or leaves a power-saving state.
Each of those uses very little on average and takes milliseconds to tens of milliseconds when it runs.

## Tension

Every interruption is a thing a designer chose and would choose again.
This is the plot that removes the last place to point. The slow moment is not a bug, a leak or an oversight: it is maintenance, contention or power management, and eliminating the activity would cost the system more than the pause does. So there is no bad machine in the fleet, no better machine to buy, and nothing to escalate. And the arithmetic gets worse as the fleet gets better organised, because **these activities are many and independent across machines**: the chance that some machine is busy at a given instant rises with the number of machines and does not fall with the quality of any one of them.
