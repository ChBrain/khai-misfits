# Plan: Answer in Ten Milliseconds

## Taxonomy

A **mandate**: the intent of [the component seat](position_component.md), inside [The Last One to Answer](play_the_last_one_to_answer.md).

## Owner

- Owner: [Component](position_component.md)

## Direction

Answer quickly, almost always, and correctly every time. Take a second occasionally, because something necessary is running, and return the right result regardless.

## Orders

([The Server](persona_the_server.md) answers in about ten milliseconds ninety-nine times in a hundred, and takes a second on the hundredth because memory is being reclaimed or a log compacted.)

## Implementation

([The Fleet](place_the_fleet.md), where a hundred of these sit; the [answering](process_answering.md) process against [the ninety-ninth percentile](piece_the_ninety_ninth_percentile.md); the slow case caused by [the legitimate pause](piece_the_legitimate_pause.md).)

## Targets

- [ ] the target is met ninety-nine times in a hundred, which is a good server
- [ ] the slow case is correct work rather than a fault
- [ ] no threshold is failed and no defect is available to remove
- [ ] a better machine of the same kind changes the rate and not the structure
