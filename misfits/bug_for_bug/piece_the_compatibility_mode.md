# Piece: The Compatibility Mode

## Taxonomy

[The Issue Tracker](place_the_issue_tracker.md). The way out that keeps both roads open forever.

## Owner

- Project: khai-misfits

## Place

Proposed at [the issue tracker](place_the_issue_tracker.md) once the revert has settled, as the way to have the fix without the outage.

## Load Bearing

It works, and it doubles the surface permanently.
Keeping the old behaviour available alongside the corrected one lets existing systems continue and new ones be right, which is the only answer that serves both: and it means maintaining, testing and reasoning about two behaviours instead of one, for as long as anybody remains on the old road, which is indefinitely, since nobody who is working has a reason to move.

## Apparent

A switch, a flag, a version header, a document type declaration: a small, contained, entirely sensible mechanism.
The pragmatic answer, chosen by serious people repeatedly.

## Yearbook

Introduced as a transition, and retained as a permanent second implementation.
Multiplies with each subsequent decision, so the combinations that must be tested grow while the original accident stays exactly where it was.
