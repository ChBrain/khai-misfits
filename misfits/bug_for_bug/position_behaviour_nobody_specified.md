# Position: Behaviour Nobody Specified

## Taxonomy

[Bug for Bug](play_bug_for_bug.md). The seat that is an accident and reads as a promise.

## Owner

- Project: khai-misfits

## Has

A stable sort, a particular wording, an order of fields, a call fast enough to loop.
Presence on every run, and absence from every document.

## Orders

Happen.
Happen the same way each time.

## Loses

Any mark distinguishing it from a guarantee.
Nothing about a running system labels which of its behaviours were promised and which merely occurred, so no experiment available to a caller can separate the two: the distinction lives in a document, and the document is not the thing anybody executes.

## Drives

Toward being depended upon without ever having been offered.
