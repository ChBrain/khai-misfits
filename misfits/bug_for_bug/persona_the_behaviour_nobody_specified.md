# Persona: The Behaviour Nobody Specified

## Taxonomy

[Behaviour Nobody Specified](position_behaviour_nobody_specified.md). The accident, observable and true on every run.

## Owner

- Project: khai-misfits

## Projection

A sort that happens to be stable. An error message with a particular wording. A field returned in a certain order. A call fast enough to put in a loop.
Not documented, not intended, not forbidden.

## Action

Happens, every time, identically.
Is observed by anybody who looks, and looking is what using it consists of.

## Shadow

Is indistinguishable from a guarantee, from outside.
Nothing about the running system marks which of its behaviours were promised and which merely occurred, so a caller cannot tell a contract from an accident by any experiment available to them: the distinction exists only in a document, and the document is not the thing anybody is running against.

## Tell

Was never a decision, and becomes a requirement.
