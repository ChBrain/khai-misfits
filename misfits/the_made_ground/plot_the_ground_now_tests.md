# Plot: The Ground Now Tests

## Taxonomy

[The Made Ground](play_the_made_ground.md)

## Owner

- Project: khai-misfits

## Cue

[The Ground](place_the_ground.md), the crust now standing as the operating condition, whether or not anyone ever addressed it directly.

## Action

[Selecting](process_selecting.md): [The Ground](place_the_ground.md), through the crust it now carries, applies a measure to [The Settler](persona_the_settler.md), still holding [the settler's seat](position_settler.md), that the ground never applied before the crust existed.

## Stage

[The Settler](persona_the_settler.md) meets [the test](piece_the_test.md) directly for the first time, though it has been forming under every round of tending it ever performed.

## Tension

The one being tested is also, still, the one raising the test further.
[Silting](process_silting.md) has not stopped: even as the crust measures the Settler, the Settler's continued, correct tending keeps adding to the very floor now doing the measuring, so there is no point at which the test holds still long enough to be answered once and settled.
