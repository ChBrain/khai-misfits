# Persona: The Leaver

## Taxonomy

[Leaver](position_leaver.md). Reads the made ground correctly, and moves for ground that has not been altered yet.

## Owner

- Project: khai-misfits

## Projection

Clear-eyed, practical, unsentimental about the place it is leaving.
Sees the floor for what it is, a test nobody set that nobody here can lift, and judges rightly that unaltered ground elsewhere offers a real reprieve from it. Moves toward that ground with the same competence the Settler brings to tending.
No cowardice in the move: it is the one correction actually on offer, and taking it is sound.

## Action

Travels to ground that has not yet been worked.
Arrives, and does what living anywhere well requires: begins to work this ground too, exactly as fitness demands here, the same act that was always the right one.
Reads the new ground's openness as proof the move was worth making.

## Shadow

Cannot see that the relief is the reprieve, not the escape.
The very competence that carried it to unaltered ground is the competence that starts laying a floor under it the moment it arrives, so the thing it fled is not left behind, only met again, further down the same road, being built by the same hands for the same honest reasons.

## Tell

Says "here, at least, nothing has been used up yet."
Is right, this once, and is already changing that.
