## Load Bearing

It is the only thing that separates the procedure from everything that accompanies it, and it is an operation.
Blinding requires the control arm to believe it received the treatment, which for a procedure means anaesthetic, an incision and a scar. That is a real harm imposed for information, so the justification required is high and is usually not met. There is no lesser version: a control arm that knows it had nothing done is not blinded, and an unblinded control measures the thing being controlled for.
