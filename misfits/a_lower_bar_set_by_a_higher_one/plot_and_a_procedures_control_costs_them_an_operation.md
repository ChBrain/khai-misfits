# Plot: And a Procedure's Control Costs Them an Operation

## Taxonomy

[A Lower Bar Set by a Higher One](play_a_lower_bar_set_by_a_higher_one.md)

## Owner

- Project: khai-misfits

## Cue

The same design, proposed for a procedure.

## Action

[The Sham Incision](piece_the_sham_incision.md) is written into a protocol and taken to [the committee room](place_the_committee_room.md).

## Stage

The identical comparison, at a wholly different price.

## Tension

Blinding requires the control arm to believe it was treated, and for a procedure that means an anaesthetic, an incision and a scar.
There is no lesser version to fall back on: a control arm that knows nothing was done is not blinded, and an unblinded control measures the very thing being controlled for. So the cost of the comparison is set by what the intervention is, and the comparison that costs a swallow in one class costs a wound in the next.
