# Plot: When the Trial Does Run It Sometimes Overturns the Practice

## Taxonomy

[A Lower Bar Set by a Higher One](play_a_lower_bar_set_by_a_higher_one.md)

## Owner

- Project: khai-misfits

## Cue

The rare occasion on which a sham-controlled trial is justified, funded and approved.

## Action

A sham-controlled comparison is completed, and the procedure is found no better than the sham at [the operating theatre](place_the_operating_theatre.md).

## Stage

A widely used, well-regarded operation, found to add nothing to its own placebo.

## Tension

The gap was carrying real error, which is how anybody knows it is a gap and not a formality.
Where the comparison has been made, in arthroscopic surgery for knee osteoarthritis and in vertebroplasty for painful vertebral fractures among others, established procedures have failed it. That is not a claim about any procedure that has not been tested, and it is the reason the untested class cannot be assumed fine: the tests that have been run are a small and non-random sample, and the ones that were run found something. So the difficulty is demonstrated rather than theoretical, and demonstrated by the very rarity that constitutes it.
