# Persona: The Committee

## Taxonomy

[Committee](position_committee.md). The one that refuses the control arm, rightly.

## Owner

- Project: khai-misfits

## Projection

A protocol proposing to anaesthetise volunteers, cut them, and do nothing inside.

## Action

Reads it.
Refuses, or permits it only where the case is exceptional and the incision minimal.

## Shadow

Is applying the correct rule to the correct object and closing the only clean comparison.
A control arm that costs its members an anaesthetic, a wound and a recovery is not the same object as a control arm that costs a sugar pill, and treating them alike would be the error. So this seat is not obstructing science: it is protecting people from a harm done to them for somebody else's information, which is the oldest rule there is. That the rule falls exactly across the one comparison that would settle the question is arithmetic and not a conflict of values.

## Tell

Protects the volunteer, and the protection is the reason nobody knows.
