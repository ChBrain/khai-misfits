# Place: The Next Time

## Taxonomy

[The Worst and the Last](play_the_worst_and_the_last.md). Where the choice whether to return is made, driven by the summary the memory kept and not by the episode itself. Hosts [The Whole Weighed](plot_the_whole_weighed.md).

## Owner

- Project: khai-misfits

## Shown

A decision at hand: whether to go back for the same procedure, the same trial, the same hard stretch, weighed by whatever the memory offers of it.

## Holds

[The Reckoning](piece_the_reckoning.md).
The lived sum set back against the peak-and-end verdict, an attempt to count the duration into a choice already leaning on two moments.

## Offers

A last chance for the whole episode to matter to the choice, if the sum can be raised against the verdict already reached.

## Withheld

Priority. The verdict is settled at the Looking Back before this place is reached, and the summary speaks first and loudest; weighing the whole back in is a correction against the grain, not the ground the choice starts from (Kahneman).
