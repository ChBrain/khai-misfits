# Plot: The Same Sum, Other Way

## Taxonomy

[The Far End of the Wire](play_the_far_end_of_the_wire.md)

## Owner

- Project: khai-misfits

## Cue

Current, impedance and distance, unchanged, with the current now running the other way.

## Action

[Turning back](process_turning_back.md), completed: [The Climbing Volt](persona_the_climbing_volt.md), holding [Climbing Volt](position_climbing_volt.md), rises along the run instead of falling along it.

## Stage

[The Tap Setting](piece_the_tap_setting.md) does not move. Nobody adjusts it, nobody could improve it, and it goes on applying the same lift it has applied since commissioning.

## Tension

The protection has become the pressure without anybody touching it.
The lift existed to stop the far end sagging under load and it is still doing exactly that, which is why the far end is now the highest point on the road rather than the lowest. There is no fault to find, no component to replace and no setting to correct, because the same number is simultaneously the right answer for a winter evening and the wrong one for a bright spring noon, and a regulator has one setting.
