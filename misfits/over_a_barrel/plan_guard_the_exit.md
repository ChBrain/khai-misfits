# Plan: Guard the Exit

## Taxonomy

A **standing plan**: the intent of [the investor's seat](position_investor.md), inside [Over a Barrel](play_over_a_barrel.md).

## Owner

- Owner: [Investor](position_investor.md)

## Direction

Keep an outside option: build general rather than specific, or invest less, or not at all, so that whatever the terms become you are never left holding an asset worth almost nothing anywhere but here. Weigh the value the tight fit would create against the squeeze it would expose you to, and where the squeeze is foreseeable, take the smaller, safer deal.

## Orders

([The Investor](persona_the_investor.md) builds general through [Withholding](process_withholding.md) at [the Site](place_the_site.md), declining [the Investment](piece_the_investment.md) whose specificity it could be squeezed on, so [the Underinvestment](piece_the_underinvestment.md) leaves the best deal unmade.)

## Implementation

([The Site](place_the_site.md) offers the choice between a tight fit and a safe one; the [withholding](process_withholding.md) process takes the safe one, so the surplus that only the specific asset would create is foregone, a loss authored by no one and never seen because the thing that would have caused it was never built.)

## Targets

- [ ] an outside option is kept, building general rather than specific, or less, or not at all
- [ ] the value of the tight fit is weighed against the exposure it opens, the retreat taken where the squeeze is foreseeable
- [ ] the specific asset that would create the most value is declined, soundly, not from failure of nerve
- [ ] the largest gains go unmade, the loss never appearing because the specific investment was never built
