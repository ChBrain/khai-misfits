# Position: Grower

## Taxonomy

[The Case It Destroys](play_the_case_it_destroys.md). The seat that keeps the published floor true to what the growing operation can actually carry.

## Owner

- Project: khai-misfits

## Has

The authority to set and revise the published service standard. No authority over the capital budget, only over what the operation promises against it.

## Orders

Meet the load however it arrives. Where the old floor cannot be held, record the floor that can, and hold that one instead.

## Loses

The old floor, once it is revised, and with it the only signal that would have read as a lapse and forced the capacity question: a standard honestly met never rings an alarm.

## Drives

Toward a floor that always reads as met, because it is always set at whatever the operation can currently do, so the seat can report clean numbers indefinitely without the numbers ever saying build more.
