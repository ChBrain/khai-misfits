# Process: Weighing Them Against Each Other

## Taxonomy

## Owner

## Direction

Toward a ranking of the members of a set against one another, done as well as mass measurement can be done.

## Lever

Relative measurement, which is the only kind available inside a set that contains its own definition.

## Echo
