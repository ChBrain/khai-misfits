# Plan: Keep It Safe

## Taxonomy

A **custodial duty**: the intent of [The Keepers](persona_the_keepers.md), inside [Exactly One Kilogram](play_exactly_one_kilogram.md).

## Owner

- Owner: [The Keepers](persona_the_keepers.md)

## Direction

Preserve an object that cannot be replaced. Keep it from air, handling, temperature and people, and disturb it as seldom as the work allows, which is very seldom indeed.

## Orders

(Three nested [bell jars](piece_the_bell_jars.md); a safe in [the safe at Sevres](place_the_safe_at_sevres.md) opened only with separately held keys; removal only for official verification; a written procedure for every operation.)

## Implementation

([The Safe at Sevres](place_the_safe_at_sevres.md); the [sitting still](process_sitting_still.md) process; a century in which the correct action is almost always to do nothing.)

## Targets

- [ ] the artefact is protected from every source of change that protection can reach
- [ ] handling is minimised, because handling is perturbation
- [ ] the accumulation is slowed to about a microgram a year, which is what makes a century of use possible
- [ ] the record contains three observations, because looking more often would have been the worse custody
