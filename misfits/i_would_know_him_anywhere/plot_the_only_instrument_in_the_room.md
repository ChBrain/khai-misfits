# Plot: The Only Instrument in the Room

## Taxonomy

[I Would Know Him Anywhere](play_i_would_know_him_anywhere.md)

## Owner

- Project: khai-misfits

## Cue

An honest witness, a clean procedure and a confident identification, put in front of twelve attentive people in [the witness box](place_the_witness_box.md)'s courtroom.

## Action

[The Twelve](persona_the_twelve.md), holding [Twelve](position_twelve.md), weigh the identification heavily, because on every visible dimension it deserves to be weighed heavily.

## Stage

Cross-examination tests consistency, opportunity, lighting, distance and duration, and finds each of them exactly as stated.

## Tension

The accurate identification and the mistaken one are the same object here, on every dimension this place can measure.
The same certainty, the same consistency, the same absence of motive, the same willingness to be tested. So the apparatus built to separate reliable testimony from unreliable testimony is trained entirely on the qualities the two share, and there is no question the jury could have asked, no demeanour it could have read and no test available that would have told them apart. Among the eyewitness cases later undone by DNA, a large share crossed this same line.
