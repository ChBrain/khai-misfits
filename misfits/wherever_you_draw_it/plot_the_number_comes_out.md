# Plot: The Number Comes Out

## Taxonomy

[Wherever You Draw It](play_wherever_you_draw_it.md)

## Owner

- Project: khai-misfits

## Cue

[Drawn for Something Else](piece_drawn_for_something_else.md): a file of area rows, and a model to fit to it.

## Action

[Aggregating](process_aggregating.md): individuals are summed into areas, which is where the relationship is constituted.

## Stage

[Estimating](process_estimating.md): [The Analyst](persona_the_analyst.md), in [the computation seat](position_computation.md), returns a coefficient on [Compute the Coefficient](plan_compute_the_coefficient.md).

## Tension

Here everything is done correctly and the correctness is the problem.
The specification is defensible, the diagnostics pass, the standard errors are computed properly, and
a second analyst given the same file returns the same number to the last decimal.
**The aggregation is not a step before the analysis: it is the analysis's first operation.** The
variance it removes and the covariance it creates are properties of the boundaries rather than of the
people, so the relationship being estimated is constituted by the map and only measured by the model.
And every diagnostic that would catch a misspecification is computed **inside** the partition, so the
apparatus is complete, is passed, and is silent about the one thing.
