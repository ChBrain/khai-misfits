## Load Bearing

Without it the play is a version of researcher degrees of freedom and the remedy already exists.
It is load bearing because **pre-registering the zoning changes the analyst's standing and not the
estimate**: naming in advance which arbitrary partition will be used makes the analysis honest and
leaves the number exactly as dependent as it was. The forking-paths problem is that the flexibility
was hidden. This one is that there is no correct option to disclose.

## Apparent

one return the same coefficient from the same units.
