## Tension

Here the harm lands, on somebody nobody has misled.
The estimate looks like every other estimate. The interval beside it looks like every other interval
and describes a resampling that did not happen, so **the page has one slot for uncertainty and prints
the wrong one**: the more carefully the sampling error is reported, the more confidently the
dependence is hidden.
And the remedy the disciplines have built for analytic freedom does not reach it.
**Pre-registering the zoning changes the analyst's standing and not the estimate.** Naming in advance
which arbitrary partition will be used makes the study honest and leaves the number exactly as
dependent as it was, because the forking-paths problem is that the flexibility was hidden and this
one is that there is no correct option to disclose.
