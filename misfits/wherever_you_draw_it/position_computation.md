# Position: Computation

## Taxonomy

[Wherever You Draw It](play_wherever_you_draw_it.md). The seat of the model: specification, fitting, and the estimate that comes out.

## Owner

- Project: khai-misfits

## Has

Data published at the units, and no access below them.
A correctly specified model and the standard diagnostics.
Every check the method offers, all of which it passes.

## Orders

Fit the model.
Check the assumptions.
Report what it returns.

## Loses

Any instrument that reads the thing at issue.
Residuals, leverage, collinearity and fit are all computed **within** the partition, so the entire
diagnostic apparatus is downstream of the choice it cannot see: **a model perfectly specified for
these units is a model perfectly specified for these units**, and no test inside it asks about others.

## Drives

Toward a correct estimate,
which it produces,
so the seat that gets everything right is the seat with no way to be wrong about the one thing.
