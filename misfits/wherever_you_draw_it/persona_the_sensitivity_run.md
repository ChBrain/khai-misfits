# Persona: The Sensitivity Run

## Taxonomy

[Recourse](position_recourse.md). The honest remedy: compute it again at many zonings and show what happens.

## Owner

- Project: khai-misfits

## Projection

Dozens or thousands of alternative partitions, each admissible, each producing an estimate.
The most rigorous thing anybody can do about this.
Genuinely informative about the size of the problem.

## Action

Re-cuts.
Recomputes.
Reports a spread.

## Shadow

That it measures the difficulty and cannot resolve it.
**The spread is not a confidence interval and there is no estimator inside it**: every value in the
range came from an admissible partition and nothing ranks them, so the output is a statement that
the answer depends on a choice, delivered to somebody who still has to make the choice.

## Tell

Is the correct response.
Ends with the same question it started with.
