# Process: Estimating

## Taxonomy

[Wherever You Draw It](play_wherever_you_draw_it.md). Fitting the model and reading the coefficient off it.

## Owner

- Project: khai-misfits

## Initiated by

[Aggregating](process_aggregating.md), and a dataset of area rows.
At [the table](place_the_table.md), in an afternoon.

## Direction

Toward a correct estimate of the relationship in these data.
Everything here is right. The specification is defensible, the diagnostics pass, the standard errors
are computed properly, and a second analyst given the same file returns the same number.

## Lever

Specification, which is real and reaches other problems.
It does not reach this one: every diagnostic the method offers is computed **inside** the partition,
so the apparatus that would catch a misspecification is silent about the units it was run on.

## Echo

A coefficient with a sign and a magnitude,
an interval describing a resampling that did not happen,
and no residual anywhere that points at the map.
