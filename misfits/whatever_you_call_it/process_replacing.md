# Process: Replacing

## Taxonomy

[Whatever You Call It](play_whatever_you_call_it.md). Doing the whole thing again, with the experience of having done it before.

## Owner

- Project: khai-misfits

## Initiated by

A word that has turned, and the same reasons as last time.
At [the style guide](place_the_style_guide.md), with a shorter interval than the round before.

## Direction

Toward a longer, more technical, more recently coined expression.
This is learned behaviour and it works: unfamiliarity slows the association, so each round buys more
time than a plain word would.

## Lever

Awkwardness, which is the only dial with any effect on the interval.
It is the same dial as usability read backwards, so the process buys duration with the property that
makes a word a replacement.

## Echo

A word that lasts longer and is harder to say,
a guide entry written as though it were permanent,
and the same seat occupied by somebody else in due course.
