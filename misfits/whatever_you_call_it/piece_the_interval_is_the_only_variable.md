# Piece: The Interval Is the Only Variable

## Taxonomy

[Whatever You Call It](play_whatever_you_call_it.md). Unfamiliarity buys time, and unfamiliarity is the same property as being hard to use.

## Owner

- Project: khai-misfits

## Place

At [the recourse seat](position_recourse.md), choosing between a plain word and a technical one.
In every replacement that is longer than the one before it.

## Load Bearing

Without it the play has no lever at all and reads as fatalism.
It is load bearing because **there is exactly one dial and it is double-ended**: a longer, more technical,
more recently coined expression genuinely does last longer, and it lasts longer by being harder to say,
so duration is bought with the property that makes a word a replacement in the first place.

## Apparent

That this is a trade-off to be optimised.
It is, and the optimum still expires; what the dial changes is how often the seat is occupied, not
whether it is.

## Yearbook

The observation that each round of replacement tends to be longer and more technical than the last, which
is learned behaviour and does work.
