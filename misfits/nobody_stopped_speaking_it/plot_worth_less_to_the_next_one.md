# Plot: Worth Less to the Next One

## Taxonomy

[Nobody Stopped Speaking It](play_nobody_stopped_speaking_it.md)

## Owner

- Project: khai-misfits

## Cue

The following parent, in the same kitchen, with the same two languages.

## Action

[Closing the channel](process_closing_the_channel.md) has run once more, and [the falling return](piece_the_falling_return.md) is recomputed.

## Stage

The answer is cleaner than it was, because fewer of this child's own generation will speak it.

## Tension

Each closure improves the case for the next, which is what turns a drift into a slide.
The worth of giving a child the home language depends on who its generation can use it with, and that population falls with every household deciding as the last one did, so the case for keeping it is weakest exactly when it is most needed. No parent is wrong about their own arithmetic, and each meets the falling return as a plain fact about the world rather than as the sum of the parents before them, which it is.
