# Position: Advocacy

## Taxonomy

[Only From Someone Like Us](play_only_from_someone_like_us.md). The seat sent to persuade, and staffed by whoever is qualified to hold it.

## Owner

- Project: khai-misfits

## Has

A brief, a budget, a set of accurate figures and a field day to run.
Training, a credential, a salary from an institution, and usually an accent from elsewhere.
Genuine competence at the subject.

## Orders

Get the practice adopted.
Reach everybody, which it does.
Be credible, which it is, on every dimension it can control.

## Loses

The one property that would make its message carry.
**Every qualification for this seat is a dimension of difference from the people it is sent to**, so the
post is filled, correctly, by the person least able to persuade from it, and improving the appointment
makes it worse.

## Drives

Toward complete coverage and an honest case,
which it achieves, county by county,
so the seat whose function is persuasion is the one from which persuasion does not travel.
