## Place

## Load Bearing

It is a real advance and it is an advance in stating the exchange rather than in escaping it.
A formal guarantee replaces the hope that a file is safe with a bound on how much any release can reveal, holds against an adversary with arbitrary outside information, and forces the trade to be set deliberately rather than discovered afterwards. What it does not do is give both. The parameter has to be chosen, the accuracy given up is real, and at the largest deployment yet attempted the published analyses put the loss where the smallest places and the smallest groups are, which is where the data was most needed and least substitutable.
