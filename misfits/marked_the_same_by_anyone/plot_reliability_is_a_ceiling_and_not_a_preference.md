# Plot: Reliability Is a Ceiling and Not a Preference

## Taxonomy

[Marked the Same by Anyone](play_marked_the_same_by_anyone.md)

## Owner

- Project: khai-misfits

## Cue

An argument that an assessment should capture what matters even if it is hard to score consistently.

## Action

[The Ceiling](piece_the_ceiling.md) is applied: the correlation an instrument can have with what it measures is bounded by how consistently it measures anything.

## Stage

The trade everybody assumes they are making is not available.

## Tension

A result from 1904 caps the second quantity by the first, which removes the move the whole debate rests on.
It is not that consistency is preferred to substance by cautious institutions: it is that an instrument nobody can apply twice the same way cannot be valid, however well it captures what matters, because validity is bounded by the square root of reliability. So the reformer who offers to accept a looser instrument for a truer measure is offering something arithmetic will not deliver, and the examiner declining is not being timid.
