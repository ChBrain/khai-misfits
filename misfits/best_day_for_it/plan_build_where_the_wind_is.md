# Plan: Build Where the Wind Is

## Taxonomy

A **standing plan**: the intent of [the developer's seat](position_developer.md), inside [Best Day for It](play_best_day_for_it.md).

## Owner

- Owner: [Developer](position_developer.md)

## Direction

Put the capital where the resource is best, since that is the whole of the job and the capacity factor is the number the returns are built on. Read the resource map, take the best available ground, and expect every other developer of the technology to be reading the same map and reaching the same conclusion, because they are. Bid zero into the market, not as a tactic but because a plant with no fuel has a marginal cost of nothing and any other number would misstate the economics. Do not decorrelate on purpose: siting on poorer ground to be less simultaneous with the rest of the class would destroy this project's returns in order to raise rivals' revenue, and no board would approve it. And when it is proposed that this seat fund the storage or the transmission that would break the correlation, decline, because the benefit would land on every generator of the class alike and a board asked to spend shareholders' money improving competitors' returns would refuse and would be right to.
