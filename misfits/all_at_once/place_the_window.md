# Place: The Window

## Taxonomy

[All at Once](play_all_at_once.md). The brief span after [The Expiry](piece_the_expiry.md) in which every miss lands together. Hosts [The Backend Buckles](plot_the_backend_buckles.md), [No One Cut the Line](plot_no_one_cut_the_line.md).

## Owner

- Project: khai-misfits

## Shown

Nothing to any single request: the window is not a place a request perceives, only one it passes through in the same breath as every other request that missed alongside it.
From outside, what is shown is the flood: recomputation calls arriving at [The Backend](persona_the_backend.md) in a burst that a graph of load would show as a single spike.

## Holds

Every recomputation the current lapse produced, held together for as long as they take to resolve.
The window is as wide as the slowest recompute, no more: once the first one to finish repopulates [The Key](place_the_key.md), later arrivals within the same span still miss, but arrivals after it resolves find the front warm again.

## Offers

The one honest reading of the misfit: that the overload is not standing, it is a pulse.
The window opens exactly at the shared expiry and closes as soon as the value is recomputed and re-cached, so what it offers a warden reading the traffic is proof that the spike is transient, tied to a moment and not a condition.

## Withheld

Any natural stagger. Left alone, the window holds every miss the lapse produced at once, because nothing about the front or the key spaces them out on its own; that spacing has to be built in, which is the work [Scattering](process_scattering.md) does, at [The Key](place_the_key.md) and [The Front](place_the_front.md), to keep this window from opening at full width.
