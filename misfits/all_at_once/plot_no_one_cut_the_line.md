# Plot: No One Cut the Line

## Taxonomy

[All at Once](play_all_at_once.md)

## Owner

- Project: khai-misfits

## Cue

[The Front](place_the_front.md) again, replayed from [The Hit](piece_the_hit.md) through [The Miss](piece_the_miss.md) to [The Overload](piece_the_overload.md), this time read rather than lived.
Nothing in the replay is rewound or undone, only looked at again for what each move actually was.

## Action

[The Request](persona_the_request.md) on [Recompute on Miss](plan_recompute_on_miss.md), [the Cache](persona_the_cache.md) on [Serve and Expire](plan_serve_and_expire.md), and [The Backend](persona_the_backend.md) on [Answer Every Call](plan_answer_every_call.md) are read back in [their seats](position_request.md), each holding the plan it held throughout, none departed from, the ground on which [The Stampede](piece_the_stampede.md) is found to have no author.

## Stage

Run it back and no one misbehaved: [The Cache](persona_the_cache.md) served correctly and expired on schedule, every [Request](persona_the_request.md) that missed did exactly what a miss requires, and [The Backend](persona_the_backend.md) answered every call handed to it, as it was built to.
Nothing was misconfigured, no request was greedy, no operator was careless, the harm was pure simultaneity, hundreds of independently correct actions coinciding on a clock none of them set and none of them watched, the mechanism Vattani, Chierichetti, and Lowenstein formalized as the cache stampede.
It is not a bank run: no request withdrew because it feared what the others would do, none of them knew the others existed, the synchrony here is mechanical, a shared expiry timestamp, and every request would have acted identically alone.

## Tension

With no one to blame, the only lever left is the clock itself: as long as every request reads the same expiry and acts on it independently, the same coincidence recurs the next time this key goes popular and stale together, unless something is built ahead of time to keep the clock from being read the same way twice.
