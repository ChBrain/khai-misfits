# Plot: Everyone Misses

## Taxonomy

[All at Once](play_all_at_once.md)

## Owner

- Project: khai-misfits

## Cue

[The Window](place_the_window.md), opened the instant [The Key](place_the_key.md) lapsed.
Every request that was already converging on the popular entry arrives inside it within the same breath.

## Action

[Flooding](process_flooding.md): [The Request](persona_the_request.md), holding [the request's seat](position_request.md) on [Recompute on Miss](plan_recompute_on_miss.md), takes [The Miss](piece_the_miss.md), not once but as every one of the concurrent askers at once, and each independently recomputes from [The Backend](persona_the_backend.md), the many individually correct recomputations arriving together as [The Stampede](piece_the_stampede.md).

## Stage

None of the requests in [The Window](place_the_window.md) know about the others; each simply finds the key gone and does exactly what a miss requires, ask the backend, get the value, write it back.
There is no coordination and no communication, only the same shared expiry producing the same correct decision in hundreds of places at once.
What was, one request at a time, a trivial recomputation becomes, taken together, a single synchronized spike bearing down on [The Backend](persona_the_backend.md) in the same instant it stopped being shielded.

## Tension

Every action taken so far has been right: the cache expired correctly, and each request is recomputing correctly.
The harm has not arrived yet from any wrong move, only from how many correct moves just landed on the same target at the same time, and what that target does next is still open.
