# Persona: The Ache That Was Always There

## Taxonomy

[Symptom](position_symptom.md). The ordinary sensation of an ordinary body, arriving in a week when there is somewhere to file it.

## Owner

- Project: khai-misfits

## Projection

Unremarkable, and unremarked for forty years.
Is the stiffness after a long drive, the tiredness of a bad fortnight, the shoulder that has always done that.
Would never have been mentioned to anybody.

## Action

Occurs, as it has always occurred.
Is noticed, because somebody is now looking.
Is reported, truthfully, as the thing it feels like.

## Shadow

That it needed nothing new to happen.
**The mechanism needs no new sensation, only a new reason to notice an old one**, so nothing in the body has
to change for the rate of reported harm to rise, and the tablet can be doing exactly nothing.

## Tell

Is the element that predates the drug.
Is the element the drug gets blamed for.
