# Position: Examiner

## Taxonomy

[The Same Print Twice](play_the_same_print_twice.md). The seat that must be told before it can work.

## Owner

- Project: khai-misfits

## Has

Training, a mark, a question, and no stake in any answer.

## Orders

Compare. Conclude.

## Loses

Any way to unhear the assignment.
The seat cannot start without knowing what is asked and cannot remove that knowledge once it has it, and no sensation reports a judgement having moved: so the seat's own care is not an instrument against this, and produces confidence rather than correction.

## Drives

Toward an honest conclusion set partly by what it had to be told.
