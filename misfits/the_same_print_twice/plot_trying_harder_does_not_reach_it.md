# Plot: Trying Harder Does Not Reach It

## Taxonomy

[The Same Print Twice](play_the_same_print_twice.md)

## Owner

- Project: khai-misfits

## Cue

The obvious answer, which is to be careful and set the context aside.

## Action

[The Examiner](persona_the_examiner.md), holding [Examiner](position_examiner.md), does exactly that, with twenty years of practice at doing it.

## Stage

Nothing happens. There is no operation that removes a known fact from a judgement already forming, and no sensation that marks one as having moved.

## Tension

A contaminated judgement feels exactly like a clean one.
That is the whole reason care is not an instrument here: introspection returns the experience of having read the mark, on both occasions, and reports nothing about the difference between them. So the examiner's own diligence produces confidence rather than correction, and the more conscientious the expert the more firmly the conclusion is held. Nothing about this is available from inside the seat at the moment it matters.
