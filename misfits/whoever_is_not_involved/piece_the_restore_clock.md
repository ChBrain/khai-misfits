# Piece: The Restore Clock

## Taxonomy

[Whoever Is Not Involved](play_whoever_is_not_involved.md). Time to restore service: the measure that runs while the fix waits.

## Owner

- Project: khai-misfits

## Place

Running at [the night of it](place_the_night_of_it.md), from the moment the service goes down.
Extended by [the queue](place_the_queue.md), which does not know this change is different.

## Load Bearing

Without it the cost of the gate is inconvenience and a slower release train.
It is load bearing because it is where the harm **peaks**: the same control that missed the failure delays the recovery, and it delays it in the one measure that is counting while customers are affected.

## Apparent

An operational metric, of the kind reported monthly.
It reads as a number about efficiency, and it is the number in which a governance decision becomes an outage lasting hours longer.
