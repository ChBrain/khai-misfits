# Process: Narrowing

## Taxonomy

[What We Always Do](play_what_we_always_do.md). Attention restricting to the cues that have mattered before, and the channels that have carried them.

## Owner

- Project: khai-misfits

## Initiated by

Load, and the need to act under it.
At [the channels](place_the_channels.md), immediately.

## Direction

Toward acting at all, which is what restriction buys: a body weighing every marginal signal equally in a crisis would never act.
It feels like focus because it is focus, and it speeds the response measurably.
So this is efficiency rather than blindness, and it is the correct move in almost every emergency the body will meet.

## Lever

Exclusion, which is what makes a response possible at speed.
Because the useful margin is indistinguishable in advance from the rest of the margin, no version of this keeps one and sheds the other.

## Echo

A faster response,
and one cue set aside by the same rule that correctly set aside all the others.
