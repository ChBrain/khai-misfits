# Plan: Name Which Hazard You Want

## Taxonomy

A **standing plan**: the intent of [the methodologist's seat](position_methodologist.md), inside [Saved for Something Else](play_saved_for_something_else.md).

## Owner

- Owner: [Methodologist](position_methodologist.md)

## Direction

Ask what the risk set is taken to contain, which is the question nobody asked. Then fit the cumulative incidence function and the subdistribution regression, and get the answer to the clinical question. Say plainly how it does that: by retaining in the risk set subjects who have already died of the competing cause, so the hazard ratio it produces has no reading for any individual patient. Run the cause-specific analysis beside it and report that it is equally correct, answers a different question, and points the other way. Do not present either as the answer. Make no claim that the therapy is safe, only that the analysis on the table cannot say either way, and concede at once that it was correctly executed and nobody made an error.

## Orders

([The Methodologist](persona_the_methodologist.md) retains through [Retaining](process_retaining.md) at [the Reanalysis](place_the_reanalysis.md), producing [the Ghost](piece_the_ghost.md), and chooses through [Choosing](process_choosing.md) at the same place, holding [the Two Answers](piece_the_two_answers.md) and [the Boundary](piece_the_boundary.md).)

## Implementation

([The Reanalysis](place_the_reanalysis.md) is where one dataset yields two correct and disagreeing answers; [Retaining](process_retaining.md) buys the population estimate with the individual reading, and [Choosing](process_choosing.md) hands the room a question about what it was asking.)

## Targets

- [ ] the question about the risk set is asked, having been asked nowhere else
- [ ] the subdistribution analysis is fitted and its price stated: the dead are kept in the risk set
- [ ] the cause-specific analysis is run beside it and reported as equally correct
- [ ] neither is presented as the answer, and no claim is made that the therapy is safe
- [ ] the room is handed a question about what was being asked, which the data cannot settle
