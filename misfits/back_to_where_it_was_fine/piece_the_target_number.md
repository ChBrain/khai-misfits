# Piece: The Target Number

## Taxonomy

[The Catchment](place_the_catchment.md). The historical loading, correctly derived and insufficient.

## Owner

- Project: khai-misfits

## Place

Issued to [the catchment](place_the_catchment.md) as the figure to be met, and defended at every stage of consultation and appeal.

## Load Bearing

It is the right answer to the question the evidence can support, and the wrong one for the system.
The lake was demonstrably clear at this loading, which makes it the only defensible target: and it identifies the point at which the clear state failed rather than the point at which the turbid state fails, and those are far apart, so meeting it moves the lake along the branch it is on without approaching the switch.

## Apparent

Evidence-based, precise, drawn from four decades of monitoring, and proof against any challenge.
Exactly what a well-run regulatory process produces.

## Yearbook

Derived from the only branch anybody has data for, since no shallow lake supplies observations of a threshold it has not yet crossed back over.
Would have had to be set far lower on the strength of a threshold nobody had measured, which is a thing no regulator may impose.
