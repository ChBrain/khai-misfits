# Plot: Near Misses

## Taxonomy

[Too Sure to Be True](play_too_sure_to_be_true.md).

## Owner

- Project: khai-misfits

## Cue

Many observers are set to judge the same question, each on their own, before any of them has heard another's answer.

## Action

At [the Line-Up](place_the_line_up.md), [the Witness](persona_the_witness.md) meets [the Scatter](piece_the_scatter.md), the spread of near misses that truly independent honest judgments should show.

## Stage

The scatter is the signature of independence: the shape a real consensus of separate minds would take if each judge were working from the same truth but with their own error laid around it, some a little high, some a little low, agreement in the main and disagreement at the edges (Condorcet's assumption). That scatter is not noise to be embarrassed by. It is the evidence that no single cause is steering every judgment the same way, and it is exactly what Condorcet's jury theorem requires to hold: independent votes, each better than chance, converging on the truth as they are pooled. No villain stands behind the scatter or against it; the witnesses have simply not yet spoken to one another, and the spread is what honest independent judging looks like before anything else touches it.

## Tension

The spread that a true consensus should show, and the question whether it will appear.
