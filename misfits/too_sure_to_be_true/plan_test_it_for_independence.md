# Plan: Test It for Independence

## Taxonomy

A **standing plan**: the intent of [the skeptic's seat](position_skeptic.md), inside [Too Sure to Be True](play_too_sure_to_be_true.md).

## Owner

- Owner: [Skeptic](position_skeptic.md)

## Direction

Seek a dissenting judgment, rebuild the line-up, recheck the instrument, hunt for the assumption held in common, to tell a real consensus from a correlated error, since the count of agreeing voices alone cannot. Know that this spends real effort and time and the comfort of a clean answer, that it can be run on only some questions and never removes uncertainty entirely, and that its alarm is a weight on the chance of a hidden cause and not a proof that the verdict is wrong.
