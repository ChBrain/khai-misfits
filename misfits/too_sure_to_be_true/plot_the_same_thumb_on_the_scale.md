# Plot: The Same Thumb on the Scale

## Taxonomy

[Too Sure to Be True](play_too_sure_to_be_true.md).

## Owner

- Project: khai-misfits

## Cue

Beneath the judging that is about to happen, a shared error is already present, unseen by anyone who will rely on it.

## Action

At [the Line-Up](place_the_line_up.md), [the Skew](persona_the_skew.md) from [the Skew's seat](position_skew.md) on [Tilt Them the Same Way](plan_tilt_them_the_same_way.md) through [Tilting](process_tilting.md) lays [the Common Cause](piece_the_common_cause.md), the systematic error that tilts every judgment the same way.

## Stage

A biased line-up, a miscalibrated instrument, an assumption held in common: one error beneath many, leaning each of them the same direction before a single judgment has been made (Gunn et al.). This is the hinge the whole misfit turns on. Condorcet's theorem needs independence to hold; a common cause is precisely what breaks it, because it does not add scatter, it removes it, pulling every honest judge toward the same mistaken answer instead of leaving each to their own separate error. No villain lays this thumb on the scale. It is unseen and unintended, a fault in the setup rather than a hand on it, planted by no one and noticed by none of the witnesses who will soon judge under it.

## Tension

The tilt laid under every judgment, and no one aware it is there.
