# Plot: Not One Dissent

## Taxonomy

[Too Sure to Be True](play_too_sure_to_be_true.md).

## Owner

- Project: khai-misfits

## Cue

The judgments are made, each witness working alone, each honest, all of them under the same shared tilt.

## Action

At [the Bench](place_the_bench.md), [the Witness](persona_the_witness.md) from [the Witness's seat](position_witness.md) on [Say What I See](plan_say_what_i_see.md) through [Judging](process_judging.md) returns [the Perfect Agreement](piece_the_perfect_agreement.md), the honest independent judgments fallen into line, the verdict with no dissent.

## Stage

The agreement that comes back is too perfect for independent error to have produced. The scatter that should have been there, the near misses of [Near Misses](plot_near_misses.md), is gone, and its absence is itself the finding: a set of truly independent honest judgments converging on the truth would still leave some spread at the edges, while a set tilted by one shared cause converges past that point, all the way to unanimity (Gunn et al.). The Talmud holds the same instinct old: in Sanhedrin, a unanimous conviction acquits, because a verdict with no dissent at all is read as a sign that something outside the evidence, not inside it, produced the agreement. No villain sits on this bench. Each witness spoke exactly what they saw, honestly and without consulting another; it is the tilt beneath them, not any of them, that erased the dissent.

## Tension

Not one dissent, where honest independence should have left some.
