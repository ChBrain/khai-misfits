# Persona: The Regulator

## Taxonomy

[Regulator](position_regulator.md). The one who licenses the structure in front of them.

## Owner

- Project: khai-misfits

## Projection

An authority renewing a licence for one dam, with a passage standard, an evidence file and a statutory scope.

## Action

Sets a passage condition, checks it is met, and renews.
Requires improvement where the evidence supports it.

## Shadow

Regulates the only object its powers reach, which is not the object that matters.
The seat is not being narrow by preference. A licence attaches to a structure because a structure is what somebody owns, applies for, and can be held to; a condition written about a whole river would fall on parties who are not applicants and could not be enforced against any of them. Renewals arrive one at a time, decades apart, from different owners. So the instrument is per-structure because ownership is per-structure, and the quantity that decides the run has no holder to be written against.

## Tell

Enforces correctly at the only scale it has.
