# Plot: And the Protection Is Specified for That State Too

## Taxonomy

[Stopping Is the Hard Part](play_stopping_is_the_hard_part.md)

## Owner

- Project: khai-misfits

## Cue

A trip setting being chosen.

## Action

[The Control Engineer](persona_the_control_engineer.md) sets the trips and interlocks against the conditions the plant is meant to hold.

## Stage

Protection that is exact, and is about one state.

## Tension

A trip has to be set against something, and the something is where the plant is supposed to be.
A protective function fires when a measured condition leaves its acceptable band, so the band has to be specified, and it is specified against the operating point because that is what the plant is for. There is no way to write a trip that means keep the plant safe without saying safe relative to what. So the protection inherits the design's specificity exactly, which is correct, and it means the protection is about the steady state in the same way the design is.
