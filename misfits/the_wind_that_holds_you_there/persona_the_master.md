# Persona: The Master

## Taxonomy

[Command](position_command.md). The person who must choose between two readings, both of them correct.

## Owner

- Project: khai-misfits

## Projection

Competent, rested enough, and not surprised by any of this.
Knows the arc, knows the coast, has done this before and got off.
The production refuses to give this seat an error, because the trap does not need one.

## Action

Reads the situation, accurately.
Weighs carrying sail against reducing it.
Chooses, and is right, and it does not help.

## Shadow

That both branches are correct about the danger each is looking at.
Carrying sail is right about the shore and wrong about the rig; reducing sail is right about the rig and wrong about the shore. There is no vantage point from which one of them is the mistake, so this is not a judgement anybody can be better at.
It ends having decided well.

## Tell

Gives an order in a level voice.
Not because they are calm, but because there is nothing in the order that argument would improve.
