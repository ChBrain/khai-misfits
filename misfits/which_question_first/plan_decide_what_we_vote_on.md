# Plan: Decide What We Vote On

## Taxonomy

A **mandate**: the intent of [the procedure seat](position_procedure.md), inside [Which Question First](play_which_question_first.md).

## Owner

- Owner: [Procedure](position_procedure.md)

## Direction

Settle what is put to the panel and in what order, which is what presiding consists of. Do it properly, and do not expect it to matter, because in almost every case it does not.

## Orders

([The Chair](persona_the_chair.md) puts the questions in an order, takes the count that order implies, and records the outcome.)

## Implementation

([The Conference Room](place_the_conference_room.md), where the order is set; the [choosing the route](process_choosing_the_route.md) process settling [the route](piece_the_route.md); nothing about it appearing in [the judgment](place_the_judgment.md).)

## Targets

- [ ] ordering the questions is an ordinary administrative job, done properly
- [ ] the two counts agree in almost every case, so the choice is unexamined
- [ ] in the cases where they diverge, this choice is the decision
- [ ] nobody votes on the route, and it is usually not recorded
