## Load Bearing

Without it the two questions are independent and majorities on each compose into nothing.
It is load bearing because **the agreement is the cause**: a logical link between the propositions is what allows a set of majority-backed answers to be inconsistent, so the one thing everybody accepts is what makes agreement impossible.

## Apparent

Settled law, and the least interesting part of the case.
It reads as the background against which the argument happens, which is why nobody looks at it when the argument produces a contradiction.
