# Process: Tallying by Verdict

## Taxonomy

[Which Question First](play_which_question_first.md). Asking each judge only how the case comes out, and counting those answers.

## Owner

- Project: khai-misfits

## Initiated by

Three coherent views, each already resolved into a verdict.
At [the tally](place_the_tally.md), down the last column.

## Direction

Toward the answer the judges actually gave.
Not liable, not liable, liable: the defendant wins two to one. This is the intuitive count and the one most people assume is the only one available, and it is faithful to each judge's own conclusion.
And it is correct counting, with nothing concealed, exactly as the other route was.

## Lever

The verdicts themselves, which each judge has already derived correctly.
Because it never touches the elements, it needs no view about the law at all and produces none.

## Echo

A win for the defendant, announced by a court a majority of which found a contract and a majority of which found a breach.
The next case inherits a result and no usable rule.
